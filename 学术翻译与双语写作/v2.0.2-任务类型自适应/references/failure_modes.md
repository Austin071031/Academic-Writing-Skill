# 误报来源与人工复核要点（failure modes）

## 数字机检常见误报

| 现象 | 原因 | 复核处置 |
|-|-|-|
| 年份被判“数字缺失/改动” | 年份作为数字纳入比对，译文改写句式时漏写年份 | 确为漏写则补；源文无年份而译文有则为增译，须删 |
| “增译数字”实为合理换算 | 译文把 0.873 写成 87.3%（值不等但物理等值） | 判据是数值严格相等；此类写法不允许——恢复原写法，保持与源文同口径 |
| 单位形式差异 | mA/cm2 vs mA/cm²、1.4 M vs 1.4 mol/L | 前者统一写法即可；后者为等值换算，确认后在 findings 标已驳回并说明 |
| 公式内数字 | 公式段整体不译（needs_translation=false），不参与比对 | 公式以原文为准；若 task 要求译公式说明文字，人工核对 |
| 表格图片内数字 | 图片不可读；表格若为文本则参与 | 图片数字在 uncertainty 标注“未纳入机检” |
| 编号误伤 | "Figure 1"、"Table 1"、"No. 52173200" 均为真实需保留数字 | 这些数字译后应仍在（图1/表1/项目号），缺失即真问题 |

## 分级判据的边界

- 23.4→23：相对差 1.7%，判“疑似四舍五入/笔误”（中）。Agent 须查源文：源文即 23.4%，
  译文必须恢复 23.4%。
- 0.82→0.8：相对差 2.4%，判“数字被改动”（高）——分级只是初判，复核后可改级。
- 1.2 million→120万：归一值相等，matched（how=exact 或 value_only），不报问题。

## 已知噪声（本版本测试记录）

- 引用内年份经屏蔽后不比对；若作者把引用年份写错，需人工核对文献条目本身。
- "约120万" 与 "approximately 1.2 million" 互译等值通过；“约”字属语气范围，
  由引用语义边界类机制核对，本引擎不重复报告。
