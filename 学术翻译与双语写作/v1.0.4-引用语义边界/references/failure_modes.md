# 误报来源与人工复核要点（failure modes）

## 边界机检常见误报

| 现象 | 原因 | 复核处置 |
|-|-|-|
| 否定丢失误报 | 否定由句式承担：“未能观察到”“难以实现”“并非…而是”不在默认词表 | 确认否定语义保留 → custom_lexicon.json 扩展词表重跑，或标已驳回附理由 |
| 限定丢失误报 | “only two” 译作“两种（而已）”语义保留但无词表命中 | 复核语义等强后驳回并写理由 |
| 引用新增误报 | 源句段引用在上一句段末尾，译文调整句序后落在本句段 | 核对归属未变 → 驳回；归属若变须复原 |
| 语气升格误报 | certainty 词命中专业术语（“完全”在“完全氧化”中作程度描述） | 语境判断：程度副词描述物理事实可保留，结论性升格须删 |
| 参考文献缺失误报 | 条目被换行/空格重排，首 60 字符指纹未命中 | 人工核对条目实际存在 → 驳回；建议不重排文献条目 |
| "No" 误命中否定 | Grant No./Figure No. 中的编号缩写 | 引擎已对 "No." 后接数字做防护；仍命中则驳回 |

## 复核优先级

高严重度先核：引用缺失/新增、否定丢失、语气升格、增译数字、文献条目缺失。
中严重度（可能性/约数/限定丢失）逐条对照原文，注意中文常把限定并入句式
（“约”“左右”可换位，“仅”可作“只有”）。

## 已知噪声（本版本测试记录）

- “研究表明”中的“表明”会命中 suggestion：源文若是 study shows 本就对应，属正常
  等强，不报问题；只有源无译有才报升格。
- 词表按子串命中（中文），“所有”命中“所有格”等罕见组合，复核驳回即可。
