# 误报来源与人工复核要点（failure modes）

## 对齐机检常见情况

| 现象 | 原因 | 复核处置 |
|-|-|-|
| suspect_length 但翻译正确 | 源句为枚举式短语（"XRD, SEM, TEM."）或标题式短句；或源句极长含多个从句全部译出 | 对照原文确认信息完整 → 已驳回并写理由 |
| 图表编号不对应 | 译文题注把 "Figure 1" 写成 "图 1"（空格）或 "Fig.1" | 编号归一已去空白/大小写；仍不一致多为真缺失，回题注句段修复 |
| 脚注标记不对应 | `[^1]` 被误写为 `[1]` 或丢失 | 恢复 `[^1]` 标记与脚注段一一对应 |
| 未知 seg_id | 译文 JSONL 中 ID 笔误（P001-s1 写成 P001-s11）或 Agent 自行新增句段 | 改回正确 ID；新增内容并入对应句段或删除 |
| 参考文献计数不一致 | 源文献段未按 [n] 编号（著者-年份制整段一条） | 整段单条时计数为 1，属正常；按条目内容核对 |
| 公式计数不一致 | 行内公式与独立公式行的分类差异 | 独立公式行不译；行内 $...$ 在句段内保留即可 |

## 双语稿使用注意

- bilingual.md 中 〔PID·原文〕/〔PID·译文〕 成对出现；修改译文时保持 PID 不变，
  重跑 assemble_translation 即可再生成。
- 〔不译·原样保留〕段（公式、文献条目）如被改动，结构不变量会立即检出。

## 已知噪声（本版本测试记录）

- 摘要中的长句（4-5 个从句）中译比例约 2.8-3.2，接近上界，可能触发疑似；
  复核确认无漏译即可。
- 化学式串（如 "LiNi0.8Co0.1Mn0.1O2"）使源文词数偏低、比例偏高，属已知边界，
  在 findings 标已驳回即可。
