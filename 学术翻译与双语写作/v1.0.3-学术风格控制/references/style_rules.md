# 学术风格规则（style rules）

## A 类：直译痕迹（translationese）

| 类型 | 中文目标模式 | 英文目标模式 | 改写范式 |
|-|-|-|-|
| 动词名词化 | 进行/做出/作出/给予/加以/实现+研究/实验/分析/表征… | — | “进行了表征”→“表征了” |
| 被动滥用 | 被字句（密度 >0.6/百字为整体异常） | 过度被动+by 链 | 中文优先主动或“由/经/通过”；施事不明保留被动 |
| 超长前置定语 | 15+ 字连续定语+的 | 长名词串修饰 | 拆短句或后置从句 |
| 英式连接 | 对于…来说/在…的情况下/由于…的原因/作为…的/值得指出的是/众所周知 | It is well known that / With the development of / more and more / plays an important role / As we all know | 删空转套话，直接陈述 |

## B 类：语域越界

| 类型 | 模式 | 处置 |
|-|-|-|
| 宣传口吻（高严重度） | 革命性/颠覆性/突破性/完美/极大地/空前的/世界一流；revolutionary/groundbreaking/perfect/amazing | 改中性陈述或删除；确为原文评价且直译则保留并注明 |
| 口语化（中） | 东西/搞/挺/蛮/啥/咱们；a lot of / stuff / kind of | 改书面学术用语 |
| 人称不当（中） | 我/你（单数）；英文 you | 无人称或“本文/本研究”；中文学术可用“我们”视学科惯例 |
| 感叹号（中） | ! | 删 |

## 句式判据

- 中文长句 >90 字 → 建议按逻辑拆 2-3 句。
- 英文长句 >45 词 → 建议拆分。
- 整体指标：的密度 >4.5/百字 或 被密度 >0.6/百字 → 整体直译腔提示（即使单条命中少）。

## 修订纪律（红线展开）

1. 修订只动句式措辞：数字、单位、术语、引用标记、否定与限定条件逐字保留。
2. 双向守界：既去直译腔（不把英文句法搬进中文），也守克制语气
   （不趁修订把 suggest 改成 prove、把“可能”删掉）。
3. 拿不准的语义微调列入 manual_confirmations。
