# 误报来源与人工复核要点（failure modes）

## 风格机检常见误报

| 现象 | 原因 | 复核处置 |
|-|-|-|
| 被动滥用误报 | “被称为/被认为是/被誉为”系中文学术习惯被动 | 逐条看密度与语境：偶发保留，整段连用以主动改写 |
| 宣传口吻误报 | 词出现在被引文献标题、他人评价的直接引语中 | 保留并在 findings 标已驳回，注明“引文原文” |
| 第一人称误报 | 致谢、作者贡献声明中“我”合法；数学论文惯例 "we" | 按章节语境驳回；正文客观叙述中的“我”须改 |
| 超长定语误报 | 化合物全名、仪器型号本身很长 | 专名不拆；改写其前后的修饰结构即可 |
| 动词名词化误报 | “进行”后接真名词（进行曲，罕见）或固定术语 | 驳回并写理由 |
| 长句误报 | 并列枚举型长句（实验条件列表）语义清晰 | 可保留，标已驳回；优先拆多层嵌套从句 |

## 修订中的典型风险

- 拆句时丢失逻辑连接：拆后必须检查因果/转折连接词是否完整。
- 主动化时臆造施事：“被制备”改主动需确认施事是“我们/本文”还是留“由…制备”。
- 删套话时误删限定：“值得注意的是”可删，但其后的限定条件必须保留。

## 已知噪声（本版本测试记录）

- “的密度”在材料学稿件天然偏高（“…的制备…的性能”），阈值 4.5 仅作提示；
  结合逐句段问题综合判断。
- 中英混排术语（如 “HTL 的稳定性”）不影响密度统计口径（按全文计）。
