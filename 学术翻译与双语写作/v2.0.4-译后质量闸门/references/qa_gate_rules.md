# 译后质量闸门规则（QA gate rules）

## 三门检查项

| 门 | 检查项 | 严重度 |
|-|-|-|
| 数字忠实 | 数字缺失（源有译无）/ 增译数字（译有源无）/ 数字被改动 | 高 |
| | 疑似四舍五入/笔误（末位级或十倍关系） | 中 |
| | 单位形式差异（值等单位写法异） | 低 |
| 引用与语义边界 | 引用标记缺失/新增（三形态多重集比对） | 高 |
| | 否定范围丢失（no/not↔不/无/未） | 高 |
| | 语气升格（源无 certainty 译有 证明/必然/完全） | 高 |
| | 可能性/表明/约数/限定丢失 | 中 |
| | 参考文献条目缺失 | 高 |
| 缩写一致性 | 源含 (ABBR) 定义的句段译文未保留缩写 | 中 |

## 去重分工

- 同一译文数字既被判“改动”又被判“增译”：末位级相近（≤2%）归数字门的“改动”，
  纯新增（无相近源值）才归边界门“增译数字”——同一事实只报一次。
- 引用标记内部数字不参与数字比对（屏蔽），引用完整性只由边界门报告。
- 跨门 findings 保留各自维度标签（事实与数字/语义边界/术语一致性），
  qa_report 统一排序但不去维度，便于分维度统计。

## 清零纪律

- **高严重度必须清零**：修订译文（追加 translations.jsonl 同 seg_id 覆盖）或
  驳回（写明理由）后重跑闸门确认；两轮未清零 → status=partial。
- 中低严重度逐条处置（修订/驳回附理由），允许带理由保留。
- 处置痕迹全部自动进 change_log（译文 diff），可复核。

## 为什么这能提分

“结果正确性 15 分”考察术语、数字、单位、引用、否定与限定条件与原文一致、
无凭空补写。v1 各版只检一个维度，运行时代理若只跑单引擎，其余维度的错误
无人拦截；闸门把三类最高价值检查合并为交付前必过的一道，且修复清单按
严重度排序可直接执行——正确性从“抽查”变为“全量机检 + 清零纪律”。
