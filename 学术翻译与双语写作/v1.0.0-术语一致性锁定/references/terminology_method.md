# 术语一致性方法（terminology method）

## 术语候选三类来源

| 来源 | 抽取规则 | 置信特征 |
|-|-|-|
| 缩写定义对 | `full name (ABBR)`，ABBR 为 2-8 位大写开头串 | 最高：作者自定义术语，必须锁定并保留缩写 |
| 大写复合词 | 首字母大写的 1-4 词序列，全篇 ≥2 次 | 高：专有名词、方法名、材料名 |
| 高频名词短语 | 小写 token 的 2-4 元组，去停用词后全篇 ≥3 次 | 中：领域术语常高频，但含噪声，由 Agent 取舍 |

子串去重：若 A 是 B 的子串且频次不高于 B，删 A 留 B；但缩写定义信息会并到保留条目
（如 "perovskite solar cells" 高频串吸收 "Perovskite solar cells (PSCs)" 的缩写 PSCs）。

## 锁定原则

1. **材料内定义优先**：原文给出中英对照或译名时，采用材料译名。
2. **学科惯例次之**：无材料定义时按该稿学科惯例定译（rationale 写明“学科惯例”）。
3. **一次锁定，全篇统一**：locked_translation 在摘要、正文、图表题注、脚注、附录一致；
   词形变化（复数、所有格）不改变译名主体。
4. **首现全称**：缩写术语首次出现处译“中文全称（ABBR）”，其后可单用缩写；
   机检对含 `(ABBR)` 定义的句段核对译文保留缩写。
5. **拿不准不硬译**：列入 manual_confirmations（如罕见的商品名、自造缩写）。

## 学科歧义处置（同一英文词不同学科译名不同）

- cell：电池（能源）/ 细胞（生物）/ 单元（结构）——按稿件学科锁定，写 discipline_note。
- deposition：沉积（材料）/ 淀积（半导体制程）。
- conductor：导体（物理）/ 指挥（音乐，显然不适用时删候选）。
- 确需两种译法并存（如全篇两种器件名俗称并用）：登记 declared_variants，
  机检对登记的变体判合规，但应在 report 中建议作者统一。

## 核对算法（term_engine audit）

对每个锁定术语，遍历全部待译句段：源句段含术语全称或缩写 → 译文应含锁定译名
（或登记变体）；不满足 → “术语未锁定”候选（中严重度，置信度 0.85）。
汇总每术语：occurrences / compliant / violations（含句段定位与原文译文对照）。

## 为什么不全自动定译名

译名的学科正确性依赖领域知识与上下文（如 "phase" 在相图/相位/阶段间的选择），
统计方法无法可靠判断；脚本负责“选得全、核得严”，Agent 负责“定得准”，
两者分工是本 Skill 相对通用翻译工具的核心差异。
