# 误报来源与人工复核要点（failure modes）

## 术语机检常见误报

| 现象 | 原因 | 复核处置 |
|-|-|-|
| “术语未锁定”但译文正确 | 源句段中术语出现在被引文献标题、图注内的专名中，译者按语境处理 | 确认语境后可驳回（status=已驳回，写明理由） |
| 高频候选非术语 | 如 "results showed that" 类功能短语达到频次阈值 | 第 6 步审定阶段删除该候选行 |
| 缩写误判 | 括号内大写串实为化学式、型号（如 (XRD) 实为仪器缩写仍属术语；(N2) 是化学式） | 化学式/型号类候选删除或标注“原样保留不译” |
| 词形变化漏检 | 术语以复数/所有格出现（PSCs / cell's），机检按子串匹配全称时单复数差异 | re 匹配用原文术语子串；复数缩写 PSCs 已在缩写匹配内，仍漏则在 declared_variants 补词形 |
| 首现全称误报 | 术语定义句段在标题或图表题注中 | 机检只核对含 `(ABBR)` 定义的句段；标题不含定义时不触发，若触发按误报驳回 |

## 切分与保护的边界情况

- 无标点长段（OCR/转写文本）：句切分退化为整段一句，术语核对仍有效，但定位粒度变粗，
  uncertainty 中如实说明。
- LaTeX 公式行内 `$...$`：已列为受保护片段；译文不得改动 `$...$` 内容。
- 图表题注整体为一句段：术语核对覆盖题注，但题注内的分面标号 (a)(b)(c) 属受保护片段。

## 双语对照稿的阅读注意

bilingual.md 中段首 〔PID〕为结构模型坐标；术语违规定位的 seg_id 与之同坐标，
可直接跳转核对。纯译文 translation_full.md 不含坐标标记，可直接进入作者修改流程。

## 历史已知噪声（本版本测试记录）

- 单字母缩写（如元素符号 V）参与句切分保护会误并句，已改为不保护单字母句点；
  姓名首字母场景（罕见于正文）可能多切一句，对术语核对无实质影响。
- "No. 52173200"（基金号）中的 No 不是术语也不是否定词，词表已做防误命中处理。
