# 数字忠实性规则（number rules）

## 归一规则（跨语言等值判定）

| 形态 | 归一 | 示例 |
|-|-|-|
| 中文量级词 | 万=1e4，亿=1e8，千=1e3，百=1e2 | 120万 → 1,200,000 |
| 英文量级词 | thousand/million/billion/trillion | 1.2 million → 1,200,000 |
| 千分位 | 逗号去除 | 1,200,000 → 1200000 |
| 科学计数 | ×10^n / ×10^{n} | 1.5×10^-3 → 0.0015 |
| 百分/千分 | % / ‰ 作为单位保留比对 | 23.4% ≠ 23.4‰ |
| 物理单位 | 小写归一后字符串比对 | mA/cm2 与 mA/cm² 形式差异报低严重度 |

等值判定：归一值相等（容差 1e-12 相对误差）即通过；值相等但单位写法不同报
“单位形式差异”（低），由 Agent 确认系等值换算还是疏漏。

## 改动分级判据

| 级别 | 判据 | 处置 |
|-|-|-|
| 疑似四舍五入/笔误（中） | 相对差异 ≤ 源值末位单位量级（按有效位数估计）或 ≤2% | Agent 复核源文写法后修订或驳回 |
| 疑似数字笔误（高） | 目标值×10/×0.1/×100/×0.01 后与源值相等 | 移位类笔误，恢复源值 |
| 数字被改动（高） | 其余不等值 | 恢复源值 |
| 数字缺失（高） | 源有译无且无相近值 | 补回 |
| 增译数字（高） | 译有源无 | 删除或回查真实来源 |

## 引用与保护

- 引用标记内部数字不参与数字比对：[2-4] 的 2、4，(Zhang et al., 2023) 的 2023。
- 公式、URL/DOI、缩写定义为受保护片段，原样保留（DOI 中数字不比对）。
- 基金号/编号（Grant No. 52173200）是真实数字，纳入比对——“No”已做防误命中处理。

## 中英文数字表达差异（翻译约束）

- "1.2 million research articles" → "120万篇研究论文"（等值）或保留 "1.2 million"；
  禁止 "120万" → "1.2 万"。
- "over 25%" → "25%以上"（保留比较级），禁止丢 over。
- "approximately ±0.3%" → "约±0.3%"（约数与误差范围都保留）。
- "between 2015 and 2024" → "2015年至2024年间"（区间双端保留）。
- 有效数字：23.4% 三位有效数字不得改为 23%（两位）或 23.40%（四位）。
