# 基础 Agent 典型失败案例（引言写作）

1. **空转铺垫开头**：以"近年来受到广泛关注"开篇，三段之后仍无具体数据——评审判"立不住"。
   对策：第一句必须带 〔E#〕 锚点或删去。
2. **数字漂移**：把笔记中的"约 40%"写成"超过 40%"或"42%"——转述与原文不一致。
   对策：数字逐字摘自 quote；引擎 numbers 字段供核对。
3. **背景与空白两张皮**：背景铺垫 A 方向，空白突然转向 B 方向。
   对策：空白句的前提（limitation 条目）应在背景段已铺垫。
4. **贡献夸大**："首次提出""全面解决"但稿件证据不足。
   对策：贡献句注明证据位置；判断类用词在 version_notes 中说明。
5. **逐篇罗列相关工作**：一段一篇、按年份排列——"分得清"维度失分。
   对策：按路线分组，同组先比较后转述（本版本管背景，分组细则见 v1.0.1）。
6. **引用悬空**：句末 [n] 与文献表对不上，或文献表混入未引用条目。
   对策：编号只由引擎生成；validate_output 做双向一致性复检。
7. **材料不足仍硬写**：笔记没有的内容凭常识补——臆造事实。
   对策：写不出的部分标 judgment 或 uncertainty，status=partial。
