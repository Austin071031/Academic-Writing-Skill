# 研究空白推导方法

## 三种推导模式

1. **共同限制模式**（最常用）：已引工作各自有效，但共享同一局限。
   前提 = 每条工作的 limitation + 摘录；缺口 = "兼顾 A 与 B 的方案存在空白"。
2. **未覆盖场景模式**：材料明确无人考察的场景（如"干空气工况""放大工艺"）。
   前提 = 明确指出未覆盖的材料句；缺口 = "X 场景下的 …… 缺乏研究"。
3. **结论冲突模式**：两篇结论相互矛盾，说明问题未被解决。
   前提 = 两篇冲突结论各一条；缺口 = "X 的判定尚无定论"。

## 三元结构（每条空白）

```
前提（≥1，每条 = entry_ids 或 manuscript_loc + limitation + quote）
  → gap_statement（纯逻辑结论，可含概括但不可含新材料外数字）
  → paper_response（本文如何填补，含具体做法/数字）
  → response_evidence_loc（P### 或 图N/表N，必须能在稿件中找到）
```

## 写作模板（引言空白段）

> 已报道的 X 路线在 C1 条件下取得 Y1〔E#〕，Y 路线实现 Y2，但均未解决 Z（共同限制）〔E#〕；
> 因此，Q（缺口陈述）。本文提出 W，针对 Q 给出 ……（对应 response）。

## 质量标尺

- 合格空白：把 gap_statement 遮住，仅凭前提可以推出；换一个领域套不进去。
- 不合格空白："相关研究较少""鲜有报道"而无前提；"这个问题很重要所以值得做"。
- 数字纪律：gap_statement/paper_response 中每个数字都能在前提 quote 或 response_evidence_loc
  段落中找到（引擎强制）。
