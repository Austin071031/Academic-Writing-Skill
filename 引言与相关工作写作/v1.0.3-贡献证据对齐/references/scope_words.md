# 范围词清单与替代写法

## 引擎重点检查词（中文）

首次、最先、最优、最佳、最好、全面、系统、显著、大幅、极大、明显

## 替代写法

| 原表述 | 克制替代 |
|---|---|
| 首次提出 X | 提出一种 X 方法 |
| 性能最优 | 在 Y 指标上达到 Z（具体数字） |
| 全面解决 | 在 W 条件下解决（限定范围） |
| 显著提升 | 将 X 从 A 提升至 B / 提升 C% |
| 极大降低 | 降低至 D / 降低 E% |

## 处置流程

1. 能删则删（多数范围词删除后句子更可信）；
2. 必须保留时：确认证据位置文本含比较性数据（优于/超过/相比/百分比/倍数），
   并把该词写入 contributions.json 的 scope_words；
3. 引擎仍标记 overclaim_risk 的：保留则需作者在 manual_confirmations 中确认，或改写。
