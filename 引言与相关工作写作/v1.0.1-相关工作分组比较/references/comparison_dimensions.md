# 五维比较口径（comparison_rows.jsonl）

| 维度 | 填写内容 | 来源 |
|---|---|---|
| problem_setting | 该工作针对的问题设定/场景与约束 | 笔记/题名/摘要 |
| method_route | 方法路线一句话（含关键参数） | 笔记/条目 |
| data_eval | 数据与评价方式（数据集、指标、关键数字） | 笔记（数字必须一致） |
| conclusion | 主要结论一句话 | 笔记/条目 |
| limitation | 适用条件与局限（空白推导的前提） | 笔记 limitation 摘录 |

## 填写规则

- 每格 ≤60 字；无据可填时留空字符串，引擎渲染为"—（未填写）"并计入 matrix_missing_for。
- 数字必须与笔记一致；评价指标要写口径（如"200 次循环容量保持率"而非"性能好"）。
- 每条被引 entry 一行；同一 entry 被多组引用时仍只填一行（引擎按 entry_id 索引）。
- 关键条目（每组被重点转述者）必填；缺失会显著拉低"结果正确性"。
