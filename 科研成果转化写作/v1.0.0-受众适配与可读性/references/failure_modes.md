# 基础 Agent 常见失败模式与本 Skill 对策

1. **缩写不展开**：直接把论文缩写（ALD、XPS）搬进科普稿。对策：引擎逐缩写核查，未展开=critical。
2. **句长失控**：学术长句原样保留。对策：句长超限逐句定位 warn。
3. **术语墙**：连续专业术语无解释。对策：术语密度上限 + 解释语境检测。
4. **篇幅超限**：写high了忘记字数。对策：去空白计数 vs 上限 105% 判 critical。
5. **读者错配**：给投资人写机理细节、给公众写公式。对策：受众阈值表分档。
6. **事实漂移**（附带收益）：改写时数字失真。对策：align_rewrite 对齐 + evidence_map 逐值溯源；本方向主查可读性，事实核验见 transfer-fact-fidelity 版本。
7. **只给建议不给稿**：基础 Agent 易输出"改写建议清单"。对策：SKILL.md 明确"完整成稿"红线，validate 闸门要求 rewrite.md 非空。
