# transfer-genre-ledger（科研成果转化写作·文体转换映射与逐段对照台账）

把论文/技术报告按目标文体（科普文章/新闻通稿/项目申报材料/简报）的结构模板重组改写，
用脚本保证"接得住"：结构要素与论断强度对应，并交付原作者可逐段复核的对照台账——
每个源文段落有去向（保留/压缩/改写/删除+理由），每个改写段落有来源（源文段落/新增过渡），
未说明理由的删除判 critical，含数值的新增段落提示核对源外事实。

## 用途与适用条件

- 适用：给定科研源文 + 目标文体（可能含受众与篇幅上限）的转换改写任务，且需要可复核的改动台账。
- 不适用：从头写论文、纯语言润色、引用管理（另有专门 Skill）。

## 安装

目录即 Skill 本体，安装为 `/skills/weekly-skill` 即可。仅依赖 Python3 标准库；
处理 PDF 源文时需环境自带 pdftotext（评测镜像已提供）。

## 快速开始

按 `SKILL.md` Phase 0-5 执行；完整说明见 `docs/USAGE.md`，最小示例见 `examples/minimal_example.md`。

## 边界

- 不生成源文外事实；模板要素源文无支撑时标注「源文未提供」，不编造引语/联系方式/指标。
- 对齐为字符 2-gram 包含度启发式，大改写的段落可能判 partial/added，需人工结合台账确认；
  ledger 的 critical/warn 是核查入口，不替代原作者终审。
