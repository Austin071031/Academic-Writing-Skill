# 文体模板（与 genre_engine.py 内置模板完全一致）

四套模板定义了目标文体的**结构要素**、**要素映射关键词**（用于把源文段落映射到要素）与**写作要点**。
引擎按 inspection.json 的 genre 选择模板；未识别时默认「科普文章」并记 manual_confirmations。

## 一、科普文章

| 要素 | 映射关键词（内容线索） | 写作要点 |
|-|-|-|
| 标题 | （取源文标题段；无则回落核心发现段） | 一句话点出核心发现，可有悬念但不得夸大 |
| 引入钩子 | 问题、挑战、难题、为什么、想象、设想、假如、一直、困境、瓶颈 | 用读者熟悉的场景或问题引出，1-2 句 |
| 背景 | 背景、近年来、随着、已有研究、传统、现有、目前、广泛应用、然而、但是、领域 | 交代研究领域与既有进展，为发现做铺垫 |
| 核心发现 | 表明、发现、实现、首次、提出、突破、证实、显示、成功、解决 | 本文最重要的结论，论断强度与源文一致 |
| 关键数据 | 达、提升、提高、降低、下降、保持、相当于、倍（另：含数值/百分比/样本量/比较事实的段落优先） | 支撑核心发现的关键数值，数字与单位逐值保留 |
| 意义与展望 | 意义、有望、前景、未来、展望、潜力、奠定基础、推动、下一步、应用 | 成果价值与应用前景，「有望」不得写成「已经」 |
| 来源说明 | 发表、期刊、doi、论文、作者、单位、课题组、资助、基金、研究团队 | 交代论文出处/团队；源文未提供则标注「源文未提供」 |

## 二、新闻通稿

| 要素 | 映射关键词 | 写作要点 |
|-|-|-|
| 标题 | （取源文标题段；无则回落核心成果段） | 主标题点成果，可加副标题；不得使用源文没有的定性词 |
| 导语(何时何地何人何事) | 近日、日前、记者、团队、课题组、大学、学院、研究院、研究所、实验室、发表于 | 首段交代何时/何地/何人/何事，四要素缺一不可；缺项标注「源文未提供」 |
| 核心成果 | 表明、发现、实现、首次、提出、突破、证实、成功、解决、研制 | 成果一句话概括+展开，论断强度与源文一致 |
| 数据支撑 | 达、提升、提高、降低、下降、保持、相当于、倍、测试（另：含数值事实的段落优先） | 关键性能数据，数字/单位/测试条件逐值保留 |
| 引语 | 表示、说道、介绍、指出、认为、强调、告诉（另：源文引语段优先） | 研究者原话或转述；源文无引语则标注「源文未提供」，严禁虚构引语 |
| 背景 | 背景、近年来、随着、已有研究、传统、现有、目前、然而、长期、领域 | 行业/学科背景，帮助媒体读者理解价值 |
| 联系方式占位 | 联系、邮箱、电话、@、通讯作者、媒体 | 媒体联络占位；源文未提供一律写占位符并标注「源文未提供」 |

## 三、项目申报材料

| 要素 | 映射关键词 | 写作要点 |
|-|-|-|
| 立项背景 | 背景、近年来、随着、已有研究、传统、现有、目前、广泛应用、需求、战略、领域 | 领域需求与研究现状，引出立项必要性 |
| 科学问题 | 问题、机制、机理、尚不清楚、难点、瓶颈、挑战、关键科学、制约、尚未 | 凝练 1-3 个关键科学问题，不得把工程指标冒充科学问题 |
| 研究内容 | 研究内容、拟开展、围绕、针对、研究包括、拟解决、开展 | 分条列出研究内容，每条对应科学问题 |
| 技术路线 | 路线、方法、采用、通过、利用、步骤、方案、策略、构建、制备、表征 | 方法-步骤-验证链条；源文方法要点必须保留 |
| 创新点 | 创新、首次、原创、突破、区别于、不同于、独有、新颖 | 与现有工作的本质区别；「首次」须与源文一致 |
| 可行性 | 可行、基础、前期、已建立、已具备、条件、平台、经验、初步、验证 | 前期工作与条件保障；初步结果保持「初步」限定 |
| 预期成果 | 预期、目标、有望、成果、指标、发表、专利、论文、形成 | 可考核的成果形式与指标；源文未给指标不得自编 |

## 四、简报

| 要素 | 映射关键词 | 写作要点 |
|-|-|-|
| 核心结论(1段) | 表明、发现、实现、首次、突破、证实、显示、结论、成功 | 全文只保留 1 段结论，开门见山 |
| 关键数据(≤5条) | 达、提升、提高、降低、下降、保持、相当于、倍（另：含数值事实的段落优先） | 至多 5 条数据，每条带单位与条件，逐值与源文一致 |
| 支撑要点 | 显示、结果、测试、分析、验证、比较、对照、图、表 | 支撑结论的论据要点，含图表引用时保留编号 |
| 风险与限制 | 局限、限制、风险、不足、有待、仍需、挑战、尚未、初步、不确定 | 如实列出限制条件；源文未提供则标注「源文未提供」，不得隐匿 |
| 建议行动 | 建议、下一步、应当、需要、推荐、推进、计划、关注 | 面向决策者的行动建议，不得超出源文结论范围 |

## 使用规则

1. **缺失要素不编造**：mapping 中无源文段落支撑的要素，写作时在成稿相应位置标注「源文未提供」，
   并记入 manual_confirmations 请原作者补充（引语、联系方式、预期指标是最高危的三类）。
2. **要素顺序即文章结构**：按模板要素顺序组织成稿；同一源文段落可支撑多个要素，但一个事实只写一次。
3. **论断强度对应**：源文「初步表明」在任何文体中都保持「初步表明」；科普化只改表达，不改强度。
4. **数据要素优先**：含数值/百分比/比较事实的源文段落优先映射到「关键数据/数据支撑」要素，
   改写时数字与单位逐值保留，不得四舍五入或换算。
