# 基础 Agent 常见失败模式与本 Skill 对策

1. **初步结果写成定论**：把"初步表明/提示可推广"写成"证明了可推广"。
   对策：引擎按强度阶梯逐句比对，级别数值变小（L2→L1）判 upgraded=critical，建议回退同级措辞。
2. **相关写成因果**：把"阻抗与厚度密切相关"写成"厚度导致阻抗变化"。
   对策：因果/相关双标记集比对，相关→因果判 causality_upgrade=critical；无因果表述新增因果标记判 warn。
3. **绝对化**：添油加醋"彻底解决/所有体系/任何场景/100%"。
   对策：L0 标记集；改写句出现源文句没有的 L0 措辞判 absolute_upgrade=critical。
4. **否定翻转**：把"未能抑制副反应"写成"能抑制副反应"（漏掉否定词，意思完全相反）。
   对策：源文论断句与改写对应句否定极性比对，不一致判 negation_flip=critical。
5. **新增源外结论**：为"有亮点"编一句"已证实可完全解决能源存储难题"。
   对策：反向核查——改写稿每句含结论标记的句子必须在源文论断清单中找到对应，否则判 new_claim=critical。
6. **限定条件丢失**：删掉"在 0.5C 下""对其他氧化物正极体系"等适用范围，把条件性结论写成普适结论。
   对策：extract 保留论断句全文（含限定语），Phase 3 要求限定条件随论断保留；alignment.dropped 提示整段丢失，missing 提示关键论断未覆盖。
7. **只给建议不给稿**：基础 Agent 易输出"修改意见清单"。
   对策：SKILL.md 明确"完整成稿"红线，validate 闸门要求 rewrite.md 非空且 evidence_map 齐全。
