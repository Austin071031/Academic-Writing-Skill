# Worked Example（合成示例，非正式案例）

源文（硫化物固态电解质论文节选，合成）：

> 循环测试表明，包覆后电池在 0.5C 下循环 500 次容量保持率达 85.3%，而未包覆对照组仅为 62.1%。
> 界面阻抗由 320 Ω 降至 85 Ω，降低了 73.4%。XPS 分析显示 LiNbO3 层抑制了界面处 S 物种的氧化分解。
> 相关结果见图2与表1。2023 年报道的同类策略容量保持率约为 78%。

parse_source 检出关键事实：85.3%、62.1%（percent），320 Ω、85 Ω（number），73.4%、78%（percent），图2、表1（figure_ref/table_ref），以及"表明/显示"（conclusion，使本段成为关键段）。

## 改写稿片段 A（等价改写，全部判 PASS）

> 包覆后的电池循环 500 次后容量保持率达到 85.3%，没包覆的只有 62.1%。
> 界面阻抗从 320 欧姆降到 85 欧姆，下降了 73.4%。相关结果见图2与表1。
> 2023 年报道的同类策略约为 78%。

check：verbatim 7，derived 0，unverified 0 → PASS。遮蔽 token：0.5C（倍率）、LiNi0.8（化学式）、2023（年份）不参与判定。

## 改写稿片段 B（换算法，derived，仍可 PASS）

> 缓冲层厚度 0.005 μm。容量保持率 0.853，对照组 0.621。阻抗从 320 Ω 降到 0.085 kΩ，降幅约 73%。

报告换算式：
- `5 nm = 0.005 μm（单位换算）`
- `85.3% = 0.853（百分比↔小数）`
- `62.1% = 0.621（百分比↔小数）`
- `85 Ω = 0.085 kΩ（单位换算）`
- `73.4% ≈ 73%（四舍五入/±1% 容差）`

## 改写稿片段 C（端点重算）

改写稿只写"界面阻抗由 320 Ω 降至 85 Ω"，省略 73.4%。引擎按同段"由 A 降至 B"重算：
(320-85)/320 = 73.4%，且 320 Ω、85 Ω 均在改写稿中 → 判 derived，换算式 `73.4% = (320-85)/320（由端点重算）`。

- 引用"见图3"：figure_ref_unknown（critical）。
