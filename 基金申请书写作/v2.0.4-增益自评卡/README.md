# grant-innovation-precision v2.0.4（创新点差异定位 · 增益自评卡）

基金申请书写作 Skill，主攻"说得准"：创新点写清与具体已有工作的差别，
不依赖 首次/国际领先/填补空白 一类无法核验的修饰；事实台账 + 证据标记 +
材料外事实机检，交付可直接进入申请书的七要素章节稿与要素对照说明。
本版新增**增益自评卡**（gain_card.md）：反事实缺陷对照 + 修订闭环 + 机械劳动量化，
自动嵌入 report.md 末尾，增益证据显式可核验。

- **安装**：本目录即技能根，整体置于 `/skills/weekly-skill` 即可被 Agent 加载；无第三方依赖（Python3 标准库；PDF 解析可选 pdftotext）。
- **快速开始**：按 `SKILL.md` 的 13 步工作流执行；方法判据见 `references/method_rules.md`；最小示例见 `examples/minimal_example.md`。
- **边界**：不臆造材料外事实；材料缺失如实降级 partial 并登记 manual_confirmations；详见 SKILL.md"限制"。
- **仓库**：https://github.com/Austin071031/Academic-Writing-Skill/tree/main/基金申请书写作/v2.0.4-增益自评卡
