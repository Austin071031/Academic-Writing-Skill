# 01 立项依据（现状—瓶颈—我们三段链；事实句逐句带〔F〕）

【现状】固态锂电池以不可燃固态电解质替代有机电解液，是突破液态电池安全瓶颈的
重要路线。其中硫化物固态电解质 Li6PS5Cl 室温离子电导率可达 3.2 mS/cm〔F0001〕，
与液态电解液相当，被普遍视为最具工程前景的候选体系〔F0003〕。已有研究报道，
通过卤素取代与元素掺杂调控晶格极化率，可进一步拓宽硫化物电解质的电化学窗口
〔F0004〕，一批工作据此给出了多种改性配方〔F0005〕。

【瓶颈】然而，电解质本体性能的提升并未同步解决界面问题。锂金属负极与硫化物
电解质接触后发生持续副反应，界面阻抗随循环不断增长；在现有体系中，对称电池
临界电流密度普遍仅约 0.8 mA/cm²〔F0002〕，全电池循环 200 次后容量保持率降至
78%〔F0006〕〔F0007〕。更关键的是，界面副反应产物在空间上如何分布、应力与电流
如何耦合诱发枝晶萌生，现有表征手段难以原位定量，相关机制尚不清楚〔F0005〕。
"化学副反应—力学失稳—枝晶萌生"三者纠缠，使界面调控长期停留在试错层面，这是
当前领域公认的瓶颈〔F0003〕〔F0005〕。

【我们】申请人团队长期围绕硫化物电解质界面开展研究，已取得系列进展：发展的
卤素梯度电解质室温离子电导率达 4.5 mS/cm〔F0009〕，较基准体系明显提升；对称
电池临界电流密度提升至 1.6 mA/cm²〔F0010〕；组装的全电池 300 次循环后容量
保持率为 92%〔F0011〕〔F0012〕。上述成果已发表研究论文〔F0015〕（DOI
10.1000/synth-ssb-001〔F0008〕），并获授权发明专利〔F0013〕。这些前期工作表明，
梯度化界面设计能够同时改善离子输运与界面稳定性，但"为何有效、极限何在"缺乏
定量判据支撑。正是基于"现状明确、瓶颈聚焦、前期有观察"的完整链条，本课题提出
对锂金属/硫化物电解质界面开展定量化解耦与调控研究。

# 02 科学问题（1 核心 + 2 子问题 + 边界声明）

核心科学问题：锂金属/硫化物固态电解质界面处"化学副反应—力学失稳—枝晶萌生"
三者的耦合机制如何定量解耦，又可通过何种界面结构参量实现调控？

子问题 1：界面副反应产物的种类与空间分布，如何定量决定界面阻抗的增长速率？

子问题 2：在应力—电流耦合作用下，枝晶萌生的临界条件由哪些可测量参量决定？

边界声明：本课题限定于锂金属负极/硫化物电解质一侧界面的基础机制研究，不涉及
正极侧界面工程与全电池系统集成工艺，不追求器件层面的工程放大指标。

# 03 研究目标（3 条，与研究内容、技术路线逐条对应）

目标 1：阐明界面副反应产物分布与界面阻抗增长的定量关系，构筑"成分—结构—阻抗"
关联模型，预期将界面阻抗增长速率较现有基准降低 40%〔拟〕。

目标 2：给出应力—电流耦合下枝晶萌生的临界判据，预期将对称电池临界电流密度
提升至 2.5 mA/cm²〔拟〕。

目标 3：提出卤素梯次缓冲层的设计准则，预期使软包验证电芯 500 次循环容量保持率
达到 90%〔拟〕。

# 04 研究内容（3 条，编号与目标一一对应）

研究内容 1（对应目标 1）：界面副反应产物的原位定量表征与关联建模。围绕不同循环
阶段的锂金属/电解质界面，系统采集产物种类、空间分布与阻抗演化数据，构筑
"成分—结构—阻抗"定量关联模型，预期将模型预测偏差控制在 15% 以内〔拟〕。前期
观察显示梯度电解质界面阻抗增长放缓〔F0010〕〔F0011〕，可作为本内容的直接切入点。

研究内容 2（对应目标 2）：应力—电流耦合下枝晶萌生条件研究。通过可控堆压实验与
原位成像，测定不同电流密度、堆压组合下枝晶萌生的临界条件，提炼可测量的临界
判据，预期支撑临界电流密度提升至 2.5 mA/cm²〔拟〕。

研究内容 3（对应目标 3）：卤素梯次缓冲层设计准则与软包验证。在内容 1、2 给出的
定量关系与判据指导下，设计缓冲层成分梯度与厚度窗口，开展软包电芯层面验证，
预期 500 次循环容量保持率达到 90%〔拟〕。

# 05 创新点（2 条，对比锚点 + 差异表述，无不可核验修饰词）

创新点 1：提出"界面化学—力学耦合临界判据"的新思路。不同于已有工作将界面副
反应与枝晶萌生分开处理的做法〔F0005〕，本课题把副反应产物分布与应力—电流耦合
纳入同一临界判据框架，而非沿用单一化学视角；难在两类过程的时空尺度差异大、
耦合项难以分离；申请人前期已将临界电流密度提升至 1.6 mA/cm²〔F0010〕并建成
原位表征能力，具备解耦验证的直接基础。

创新点 2：构筑卤素梯次缓冲层的可控制备方法。相比现有均质缓冲层改性方案
〔F0004〕，改为成分梯度化设计，优于均质层"只改性、不解耦"的调控方式；按该
路线，界面阻抗增长速率预期较基准降低 40%〔拟〕。

支撑基础：申请人已就梯度电解质制备获授权发明专利〔F0013〕，前期全电池 300 次
循环容量保持率 92%〔F0011〕〔F0012〕，方法可行性有前期数据支撑。

# 06 技术路线（3 步骤，与研究内容逐条对应，含输入输出）

步骤 1（对应研究内容 1）：输入为不同循环阶段的界面样品与电化学阻抗数据；采用
原位谱学与显微表征获取副反应产物的成分与空间分布，结合阻抗谱拟合提取增长速率，
以机器学习方法训练关联模型；输出为"成分—结构—阻抗"定量关联模型与配套数据集
〔拟〕。

步骤 2（对应研究内容 2）：输入为步骤 1 的关联模型与可控堆压实验装置；通过变堆压、
变电流密度对称电池实验与原位成像，标定枝晶萌生的临界条件，拟合应力—电流耦合
判据参数；输出为枝晶萌生临界判据及临界电流密度验证数据〔拟〕。

步骤 3（对应研究内容 3）：输入为步骤 2 的临界判据与梯度电解质制备工艺
〔F0013〕；按判据给出的安全窗口设计缓冲层梯度与厚度，开展软包电芯组装与
长循环测试；输出为缓冲层设计准则、软包验证报告与预期指标达成情况〔拟〕。

# 07 研究基础与可行性（已完成带〔F〕，拟开展带〔拟〕，体貌分清）

已完成基础：申请人已发表硫化物电解质界面方向研究论文〔F0015〕（DOI
10.1000/synth-ssb-001〔F0008〕），已获授权发明专利 ZL202311234567.8〔F0013〕，
已结题国家自然科学基金面上项目（批准号 51972222〔F0014〕）。申请人发展的卤素
梯度电解质室温离子电导率达 4.5 mS/cm〔F0009〕，对称电池临界电流密度达
1.6 mA/cm²〔F0010〕，全电池 300 次循环容量保持率为 92%〔F0011〕〔F0012〕。
团队已建成惰性气氛固态电池组装与原位表征平台，现有博士生 6 名〔F0016〕，
掌握了界面样品制备、转移与原位观测的全套方法〔F0014〕。

可行性分析：上述平台与数据覆盖本课题三项研究内容所需的全部关键环节；内容 1
所需的原位表征能力已由前期论文验证〔F0008〕，内容 2 所需的可控堆压装置已纳入
现有平台，内容 3 依托已授权专利工艺〔F0013〕，技术风险可控。

拟开展安排：本课题拟依托上述平台分三阶段推进〔拟〕：阶段一将制备系列卤素梯度
缓冲层样品并采集原位表征数据；阶段二将构筑定量关联模型并给出枝晶萌生临界
判据；阶段三计划开展软包电芯长循环验证，预期 500 次循环容量保持率达到 90%、
临界电流密度提升至 2.5 mA/cm²〔拟〕，各阶段数据将全部留存以备复核〔拟〕。
