# grant-innovation-precision（创新点差异定位 · v2.0.1 示例成稿锚定）

基金申请书写作 Skill，主攻"说得准"：创新点写清与具体已有工作的差别，
不依赖 首次/国际领先/填补空白 一类无法核验的修饰；事实台账 + 证据标记 +
材料外事实机检，交付可直接进入申请书的七要素章节稿与要素对照说明。

**v2.0.1 单点改动（示例成稿锚定）**：新增 `examples/full_draft_example.md`——
完整合成七要素成稿示例（固态锂电池界面题材，标注"合成示例、禁止照抄"），
示范达标厚度、〔F〕〔拟〕标记密度与目标-内容-路线对应体例；SKILL.md 第 7 步
（分节撰写）开头改为先通读该示例掌握成稿形态再落稿。其余与父辈 v1.0.3 一致。

- **安装**：本目录即技能根，整体置于 `/skills/weekly-skill` 即可被 Agent 加载；无第三方依赖（Python3 标准库；PDF 解析可选 pdftotext）。
- **快速开始**：按 `SKILL.md` 的 13 步工作流执行；最小示例见 `examples/minimal_example.md`，成稿锚定示例见 `examples/full_draft_example.md`。
- **边界**：不臆造材料外事实；材料缺失如实降级 partial 并登记 manual_confirmations；详见 SKILL.md"限制"。
- **回归证据**：`regression_report.json`（13 脚本与父辈 md5 一致 + 端到端 validate PASS + 示例自洽检查）。
