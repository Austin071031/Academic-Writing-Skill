# grant-question-convergence（科学问题收敛）

基金申请书写作 Skill，主攻"科学问题收敛"：把宽泛研究兴趣收敛为可回答、可分解、
有边界的科学问题，避免问题过大或与研究方法错位。问题候选机选 + 收敛五规则机检 +
事实台账 + 证据标记 + 材料外事实机检，交付可直接进入申请书的七要素章节稿与要素对照说明。

- **安装**：本目录即技能根，整体置于 `/skills/weekly-skill` 即可被 Agent 加载；无第三方依赖（Python3 标准库；PDF 解析可选 pdftotext）。
- **快速开始**：按 `SKILL.md` 的 13 步工作流执行；完整说明见 `docs/USAGE.md`；最小示例见 `examples/minimal_example.md`。
- **边界**：不臆造材料外事实；不写过大问题；材料缺失如实降级 partial 并登记 manual_confirmations；详见 SKILL.md"限制"。
- **仓库**：https://github.com/Austin071031/Academic-Writing-Skill/tree/main/基金申请书写作/v1.0.1-科学问题收敛
