# 科学问题收敛方法判据（question_engine 判定规则）

## 收敛三判据

| 判据 | 含义 | 机检规则 | 写作判据 |
|-|-|-|-|
| 可回答 | 单一机制/对象/变量明确的问句，本课题方法能闭环回答 | 问句以"？/？"结尾；核心问题数 1-3；无过大表述 | 问句含"如何/什么/为何/多大程度"指向机制或定量关系；禁止领域工程型（系统研究/全面揭示） |
| 可分解 | 核心问题→子问题→任务的问题树 | 全节出现分解标记 | 每个核心问题分解为 2-4 个子问题，子问题与研究内容逐条对应 |
| 有边界 | 明确聚焦什么、不涉及什么 | 全节出现边界表述 | 句式「本课题聚焦于…，不涉及…，限定于…」 |

## 问题树写法（核心问题 → 子问题 → 任务）

```
核心问题（1 个，问句式）：两性离子界面修饰层如何通过偶极取向与缺陷钝化的协同作用抑制界面复合？
├─ 子问题一（其一）：偶极取向对能级排列的定量贡献有多大？〔F0018〕
│    └─ 任务：原位光电子能谱测取向—势垒曲线 + 第一性原理计算
├─ 子问题二（其二）：钝化基团与缺陷位点的作用机制是什么？
│    └─ 任务：缺陷谱学 + 瞬态光电，建立"官能团—位点—复合速率"构效关系
└─ 边界声明：聚焦界面工程，不涉及器件封装工艺的系统性研究。
```

## 过大表述词表（科学问题节命中即 high，scope_too_broad）

系统研究、全面揭示、各个方面、诸方面、全方位、彻底解决。

**收敛改写判据**：把"研究 X 的各个方面/系统研究 X"改写为"X 的哪一个具体机制/定量关系尚未阐明？"
反例：「系统研究界面工程的各个方面，全面揭示其机理。」
正例：「界面缺陷钝化机制尚不清楚：钝化基团与缺陷位点的作用机制是什么？」

## 信号词表

- **问题候选信号（seed 抽取，±50 字上下文）**：尚不清楚、机制不明、尚未、缺乏、亟待、
  有待、悬而未决、未知、谜、争议。
- **子问题分解标记（no_decomposition 判定）**：子问题、分解为、具体包括、（1）、1）、其一。
- **边界表述（no_boundary 判定）**：不涉及、边界、限定、聚焦、仅限于、排除。
- **宽泛表述警示（seed 的 warnings，材料与 task.md 双源）**：系统研究、全面揭示、
  各个方面、诸方面、全方位。

## 问题—目标—方法对齐判据（method_misaligned）

科学问题节文本与研究目标节、技术路线节分别做 grant_utils.trigram_jaccard
（中文字符 3-gram Jaccard）；**两节相似度均 <0.05 → medium（问题与目标/路线错位）**。
写作要求：核心问题的关键词（研究对象/机制变量/方法名词）在研究目标与
技术路线中逐字复现（如"偶极取向/缺陷钝化"三处同现），相似度自然达标；
阈值只抓"换题"级错位（问题写 A 领域，目标/路线写 B 领域）。

## 问题计数规则（question_count）

- 问句式：gu.cn_sentences 断句后以"？/？"结尾的句子；
- 编号条目式：行首命中 `\d+[.、）)]`、`（\d+）`、`(\d+)`、`第X个问题`、`问题X`；
- 两者取较大者视为核心问题数；期望 1-3，>4 → medium「问题数量过多，未收敛」。
  0 个问句/编号视为"未识别到问题"提示给 Agent（不自动判定，避免对纯陈述写法误报）。

## 误报来源与处置

1. **"系统性研究"不误命中"系统研究"**：黑名单不含"系统性"，"封装工艺的系统性研究"
   是边界声明内的合理名词短语，不命中。
2. **分解/边界标记出现在其他要素节**：no_decomposition 与 no_boundary 按科学问题节
   全文扫描，跨段分布即可，不要求逐段命中。
3. **method_misaligned 措辞差异误报**：问题用学术化改写、目标用条目化缩写的写法
   相似度可能偏低——写作时复现核心关键词，或第 12 步标"已驳回"并写理由。
4. **"未知"误报**：如材料写"未知杂质"属成分描述而非 gap；Agent 在第 6 步审定候选
   时剔除，seed 不做语义判定。
5. **编号条目为子问题而非核心问题**：混合写法按较大者计数可能偏高；
   建议核心问题写成问句、子问题用其一/其二，机检与人工复核结论一致。
