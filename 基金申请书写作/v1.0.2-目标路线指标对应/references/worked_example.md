# 完整标注示例（合成案例，非正式测试案例）

材料背景（合成）：钙钛矿太阳能电池界面工程方向，申请人有两性离子界面修饰前期成果。
下列四节草稿为合成文本，仅演示引擎判定，FID 均指向合成台账。

## 一、正例：3 目标-3 内容-3 路线-3 指标全对应（findings=0）

```markdown
# 研究目标

目标一：阐明两性离子修饰层偶极取向调控能级排列的机制，建立取向—电压损失定量关系〔拟〕。

目标二：揭示钝化基团与界面缺陷位点的作用机制，提出协同钝化设计准则〔拟〕。

目标三：发展放大制备工艺，实现中试条件下高效组件的可控制备〔拟〕。

# 研究内容

（一）偶极取向调控能级排列机制研究：量化两性离子修饰层偶极取向对能级排列与电压损失的影响〔拟〕。

（二）钝化基团与界面缺陷位点作用机制研究：建立构效关系，提出协同钝化设计准则〔拟〕。

（三）放大制备工艺研究：发展中试条件下高效组件的可控制备方法〔拟〕。

# 技术路线

步骤一：针对研究内容（一），合成两性离子修饰分子，原位表征偶极取向，计算能级排列，输出取向—电压损失关系曲线。

步骤二：针对研究内容（二），构建缺陷谱学平台，测定复合速率，建立构效关系，输出协同钝化设计准则。

步骤三：针对研究内容（三），开展狭缝涂布放大制备工艺试验，验证中试条件下高效组件可控制备。

# 考核指标

指标一：对应目标一，阐明偶极取向调控能级排列机制，形成取向—电压损失定量关系模型〔拟〕。

指标二：对应目标二，建立协同钝化设计准则，器件电压损失显著降低〔拟〕。

指标三：对应目标三，完成中试条件下高效组件可控制备验证，形成放大制备工艺规范〔拟〕。
```


判定说明：
- 目标↔内容：措辞共享"偶极取向调控能级排列""钝化基团…缺陷位点""放大制备工艺"等词组，

- 内容↔路线：路线条目写"针对研究内容（一）"，编号互引直接命中（ref）；
- 指标↔目标：指标条目写"对应目标一"，编号互引命中（ref），且与目标措辞重叠命中（sim）；
- 四节计数 3=3=3，无 count_mismatch；四节齐全，无 missing_section。

## 二、反例：目标三条、路线两条、缺指标节（high=2 medium=1）

```markdown

目标一：阐明两性离子修饰层偶极取向调控能级排列的机制〔拟〕。

目标三：发展放大制备工艺，实现中试条件下高效组件的可控制备〔拟〕。

# 研究内容

（一）界面偶极取向调控与能级排列研究：通过原位表征与理论计算，量化偶极取向对
界面势垒与电压损失的影响〔拟〕。

（二）缺陷钝化机制与协同设计：结合光谱与电学表征，建立构效关系。

上述两个研究内容分别支撑目标一与目标二，并为放大制备提供材料与界面基础。

# 技术路线

（一）针对研究内容（一）：合成系列两性离子修饰分子，制备模型器件，表征偶极取向。

（二）针对研究内容（二）：构建缺陷谱学表征平台，测定复合速率，输出协同钝化设计准则。

（无考核指标节）
```

```

```

| 级别 | 类型 | 说明 | 修订指令（摘要） |
|-|-|-|-|
| high | count_mismatch | 目标 3 条、内容 2 条，数量不一致（应一一对应） | 增删条目使目标与内容一一对应 |
| high | missing_section | 草稿中未找到「考核指标」章节 | 补写 # 考核指标 节，指标逐条回溯目标并标〔拟〕 |
| medium | orphan_goal | 研究目标「目标三」无任何对应研究内容条目 | 补写对应研究内容（放大制备工艺研究） |

判定说明：
- 目标三（放大制备）在内容节无任何对应条目（措辞无重叠且无编号引用）→ 真孤儿，非误报；
- 内容（二）尾段"分别支撑目标一与目标二"触发编号互引，目标一/二不被误报为孤儿；
- 修订路径：补内容（三）放大制备工艺研究 + 补路线步骤三 + 补考核指标节三条，
  重跑 draft_builder 与 audit，high 清零后 findings=0。

## 三、误报驳回示例（同义改写低相似）


重跑 audit 后该 finding 不再出现（ref 规则命中）。
