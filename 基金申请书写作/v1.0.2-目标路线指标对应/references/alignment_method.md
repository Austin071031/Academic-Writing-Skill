# 对应矩阵方法判据（alignment_engine 判定规则）

## 一、条目编号规范（机可识别体例）

引擎按**行首**模式切分四节条目，识别下列体例（阿拉伯/中文数字、全半角括号兼容）：

| 体例 | 示例 | 归一 item_id |
|-|-|-|
| 数字加点/顿号/括号 | `1.` `1、` `1)` `1）` | `1` |
| 括号数字 | `(1)` `（1）` | `（1）` |
| 括号中文数字（兼容扩展） | `（一）` `（二）` | `（一）` |
| 圈码 | `①`…`⑨` | `①` |
| 要素词+中文数字 | `目标一` `内容二` `步骤三` `指标一` | `目标一` |
| 第X条 | `第一条` `第三条` | `第一条` |

切分规则：
- 行首命中 → 开新条目；未命中行并入上一条目（续行/尾段说明不另计条目）；
- 节首无编号文字记 preamble，不计入条目并记 note；
- 整节无编号 → 每段落整体作为单条目（item_id=段N）并记 note（建议改编号体例）；
- 编号连写不换行 → 只切出一条，记"疑似编号未换行或体例混用"note 提示 Agent 复核。

## 二、四节识别

| 节 | 段落来源（draft.json 的 element 字段） |
|-|-|
| 研究目标 | element = 研究目标 |
| 研究内容 | element = 研究内容 |
| 技术路线 | element = 技术路线 |
| 考核指标 | element ∈ {考核指标, 预期成果} 的全部段落；或 element = 研究目标 且含 指标/考核/预期 信号的段落 |

## 三、对应矩阵判据

对四节跨节条目两两比对（共 6 个节对），命中任一条件即判"对应"：

1. **相似度对应（sim）**：`grant_utils.trigram_jaccard`（中文字符 3-gram，剥除〔…〕
   证据标记后计算）≥ **0.12**。
2. **编号互引对应（ref）**：条目正文显式引用他节编号——如路线条目写
   "针对研究内容（一）"、指标条目写"对应目标一"——按序号（中文/阿拉伯数字归一为
   1-based 序数）直接建立对应，score 记 1.0，不受措辞改写影响。

## 四、覆盖规则与发现等级

| 规则 | 违反 finding | 级别 |
|-|-|-|
| 每个研究目标 ≥1 条研究内容对应 | `orphan_goal` | medium |
| 每条研究内容 ≥1 条技术路线对应 | `orphan_content` | medium |
| 每条考核指标 ≥1 个研究目标可回溯 | `orphan_metric` | medium |
| 目标数 ≠ 内容数 | `count_mismatch`（消息写明"目标 3 条、内容 2 条"式事实） | high |
| 内容数 ≠ 路线数 | `count_mismatch`（"内容 X 条、路线 Y 条"） | high |
| 四节任缺（无对应 element 段落） | `missing_section` | high |

count_mismatch 只在两侧节都存在时比较（缺节已由 missing_section 报告，避免重复轰炸）。

## 五、阈值依据（0.12）

- 中文 3-gram Jaccard 对同义改写敏感：两条真实对应的条目（目标"阐明偶极取向调控
  能级排列的机制" vs 内容"偶极取向调控与能级排列研究"）共享词组约 6-10 个 trigram，
  归一化后约 0.08-0.20 区间分布；取 0.12 位于该区间下沿，**取低不取高**——
  孤儿 finding 是 medium 级候选误报（Agent 可复核驳回），漏报真孤儿才是 high 级风险。
- 编号互引规则（ref）承担"措辞完全不同但显式引用"的情形，进一步压低漏报率。
- 阈值为引擎文件顶部常量 `SIM_THRESHOLD`，可按学科语料调整；调整后须重跑 audit。

## 六、误报来源与处置

1. **同义改写导致低相似孤儿**：目标写"提升器件运行稳定性"，内容写"长时服役性能
   衰减速率调控"，语义对应但字面重叠 < 0.12 → orphan_goal 误报。
   处置：Agent 复核确有对应的，在 findings.json 将该条加 `"status":"已驳回"` 并写理由；
   建议同时在内容条目中显式引用目标编号（"（二）…：支撑目标二"）消除歧义。
2. **指标节措辞高度凝练**：指标条目过短（<10 字）导致 trigram 集合过小、相似度不稳。
   处置：指标条目写全"指标X：对应目标X，……"句式，既触发 ref 规则又保证字数。
3. **无编号节按段落切条**：引导段、尾段被计为条目，造成 count_mismatch 误伤。
   处置：四节统一行首编号体例；尾段说明文字会被并入上一条目，不另计。
4. **研究目标段落兼作指标段**：element=研究目标 且含"预期"的段落会同时进入
   研究目标与考核指标两节（自身相似度 1.0 必对应，不产生孤儿）；若不希望双计，
   独立写 `# 考核指标` 节即可。
5. **编号互引指错序号**：条目引用"内容（三）"但内容节只有两条 → 序号越界，不建对应，
   不产生 finding；Agent 写作时应保证引用序号存在（seed 计数可自查）。
