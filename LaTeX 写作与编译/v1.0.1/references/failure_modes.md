# 已知失败模式与规避（公式方向）

| 失败模式 | 表现 | 规避 |
|-|-|-|
| 改含义凑规范 | 为统一符号把材料中两个不同量并成一个 | 含义改动必须有任务/材料依据；拿不准记 uncertainty |
| eqnarray 半迁移 | 只换环境名不改 `&=&`，对齐错乱 | 按 math_rules M2 三点迁移；复编后目视 PDF 核对 |
| $$ 配对错位 | 跨行 $$ 改 \[ \] 后首尾错位 | 改前数清配对；一次只改一处并复编 |
| siunitx 版本炸 | \SI 在 v3 可用、\qty 在 v2 不存在 | 编译实测选命令；不行则退回裸正体 \mathrm{kg} 并注明 |
| \eqref 串号未查 | 编号全对但引用错对象 | Phase 2 逐条核对 M3b；这是评分点"改得对"的核心 |
| 下标一刀切 | 把 x_i 也改成 \mathrm{i} | M4 判断口诀：是词→正体，是指标→斜体 |
| 公式内中文 | pdflatex 下公式中夹中文报 Unicode 错 | 中文移出公式用 \text{}（需 amsmath+合适引擎）或改叙述 |
| 多轮编译不收敛 | 交叉引用抖动 | tex_build --until-converge 自动多轮；仍不收敛查重复 label |
| 预算耗在美观上 | 反复微调间距烧请求 | warn 级 findings 清零即停；info 级可登记不处理 |
| 无引擎也声称验证 | 没编译就写 success | 无引擎时 status≤partial，exceptions 写明 |
