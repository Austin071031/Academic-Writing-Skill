# 评分自查表（latex-table-governance v1.0.2）

## 实际效果（40）
- [ ] 任务完成度：表格相关任务要求逐项完成或标注；编译收敛。
- [ ] 结果正确性：表内数据与材料一致；无缩放/裁切掩盖；overfull>20pt 清零。
- [ ] 结果完整性：逐表体检覆盖全部 tabular；契约字段与交付物齐备。
- [ ] 可核验性：机械修复（fix_log）与人工修改（change_log）分离可回溯；
  复扫 findings 对比留痕。

## 使用增益（25）
- [ ] 质量：逐表机读体检替代抽查；T3 error 级缺陷必命中。
- [ ] 效率：简单模式机械转换覆盖大部分工程；Agent 集中处理语义问题。
- [ ] 可验证：前后两份 table_report + build_report 直接对比。

## 创新增益（15）
- [ ] 新增能力：列声明×行单元格一致性机检（含 \multicolumn 展开）、
  缩放包裹检出、受限机械转换（防误改的"简单模式"判据）。
- [ ] 方法改进：超宽表按根因分流（tabularx/longtable/减列/横排）而非一刀切缩放。
- [ ] 创新证据：table_report 的 tables[] 体检矩阵即证据。

## 可靠体验（10）
- [ ] 易用：逐字命令；异常表含 booktabs 不可用、复杂 \cline 表头等场景。
- [ ] 稳定：纯标准库、幂等；机械转换仅限简单模式防破坏。
- [ ] 异常处理：数据冲突/无优雅解/浮动堆积均有降级与登记路径。

## 生态贡献（10）
- [ ] 文档齐备；table_rules 改造范式可独立复用；GitHub 公开沉淀。
