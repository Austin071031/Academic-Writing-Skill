# 方法：确定性五级与限定语词表（uncertainty-guardian）

## 确定性五级
| 级别 | 判据 | 例 |
|-|-|-|
| 确定 | A/B 级证据且外推距离为零 | 指南明确推荐 |
| 很可能 | A/B 级证据，外推一步 | 大队列结果推广到相似人群 |
| 可能 | C 级证据或外推两步 | 小样本前瞻研究提示 |
| 有限提示 | D 级证据或单一来源 | 个案、动物实验、预印本 |
| 未知 | 材料内无证据 | 机制未明、长期安全性未知 |

外推距离定义：研究样本→目标人群（一步）、动物→人（一步）、体外→体内（一步）、相关→因果（两步）。
每跨一步降一级；两条外推叠加再降。

## 限定语词表（中英对照）
| 级别 | 中文限定语 | 英文 |
|-|-|-|
| 确定 | 表明、证实、确定 | shows, demonstrates, established |
| 很可能 | 很可能、提示…具有较强关联 | likely, probably, strongly suggests |
| 可能 | 可能、或许、提示、初步表明 | suggests, may, indicates a possible |
| 有限提示 | 有限证据提示、个案报告提示、尚不能确定 | limited evidence suggests, a case report hints, remains unclear |
| 未知 | 尚无证据、机制未明、有待研究 | no evidence, unknown, remains to be determined |

## 四类触发点与处置
1. 因果动词（导致/引起/证明/决定）且证据仅为相关 → 改为“与…相关/伴随”，或补“可能”；
2. 全称断言（首次/唯一/彻底/必然/无风险）→ 删除或加范围限定（“在本材料样本中”“截至所给文献”）；
3. 外推表述 → 显式写出外推路径并降级限定；
4. 冲突证据 → 并陈双方结果，各自加限定，指出分歧点。

## 反含糊条款
限定后句子必须仍可判定：禁止使用“或许”“某种程度上”“可能也许”这类无信息限定充数；
改写标准：第三方读完仍能回答“作者到底认为该论断成不成立、把握多大”。
