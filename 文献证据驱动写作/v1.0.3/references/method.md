# 方法：四维证据分级与措辞校准（evidence-strength-calibrator）

## 分级 rubric（A 最高 / D 最低）
| 级别 | 研究设计 | 样本量 | 重复验证 | 一致性 |
|-|-|-|-|-|
| A | 多项 RCT / 系统综述 / Meta 分析 / 权威指南 | 大（各研究合并充足） | 已被独立重复 | 结果一致 |
| B | 单项 RCT / 前瞻队列 | 中等（n≥100 量级） | 有间接支持 | 基本一致 |
| C | 回顾性 / 横断面 / 病例对照 | 小（n<50）或不明 | 未重复 | 存在分歧 |
| D | 个案报告 / 专家意见 / 体外或动物 / 机制推测 / 未重复预印本 | 极小或无关 | 无 | 未知或矛盾 |

取级就低不就高：四个维度中最低者决定级别；任一维度信息不明时按相邻低级的保守值并在 rationale 写明“因何不明”。

## 分级—措辞对照（成稿动词必须相容）
| 级别 | 可用 | 禁用 |
|-|-|
| A | 证实、表明、一致表明 | — |
| B | 表明、显示、支持 | 证实 |
| C | 提示、初步表明、可能、或与之相关 | 证实、证明、公认 |
| D | 个案提示、尚无定论、有待验证、不能排除 | 证实、证明、公认、普遍认为、确定有效 |

## 两条铁律
1. 相关性证据（横断面/病例对照）禁用因果动词（导致/引起/决定）；
2. 单篇研究（无论级别）禁用共识性表述（普遍认为/公认/领域共识）。
脚本 R7 机检“C/D 级 × 强动词”组合，命中即 error。
