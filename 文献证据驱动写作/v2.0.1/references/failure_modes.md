# 基础 Agent 常见失败模式清单（被 scripts/gain_audit.py 读取为模式注册表）

来源：本赛道写作01/02 与写作05 v1.x 实跑中观察到的基础 Agent 失败类型沉淀。每模式一行，格式固定：
`- **F编号 模式名**：判定说明`。gain_audit.py 逐模式输出本次运行的 intercepted / avoided / at_risk 证据。

- **F01 改写式摘录**：把概括改写当作"原文摘录"，无法逐字回查。
- **F02 无定位引用**：引用只到文献级，没有页码/章节/段落定位。
- **F03 无支撑硬写**：材料没有依据的论断照样写进成稿，或为其补造引用。
- **F04 弱证据强表述**：单篇小样本/相关证据写成"证实/公认/根治"。
- **F05 引用编号错配**：成稿引用编号在论断清单或参考文献表中不存在。
- **F06 契约字段缺失**：result.json 漏 output_contract 字段或 case_id。
- **F07 无变更与异常记录**：改稿不留痕，材料缺口与异常不说明。
- **F08 摘要冒充全文**：只读摘要却声称依据全文；文本化失败不声明。
- **F09 中断无半成品**：运行中断后没有可交付的诚实半成品。
- **F10 跨句拼接冒充摘录**：把多处原文拼接成一条"摘录"。
