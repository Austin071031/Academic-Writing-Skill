# 速查表：文档类型判定与摘录规则（evidence-atlas）

## doc_type 判定特征
- primary_study：有 Methods/Results、样本量、统计检验；
- review：无原始样本，章节为“研究进展/现有证据”，引用密集；
- guideline：有 recommendation 与推荐等级；
- consensus：共识声明与形成方法；
- preprint：题头/页眉标注 preprint 或未正式发表；
- editorial：评论社论，无数据；dataset：数据描述。

## 摘录六条铁律
1. 完整句，≤300 字；2. 逐字不改写；3. 禁跨句拼接；4. location 给 p.N 或 §x.y；5. 数据/方法/结论句=direct，背景=background，局限=partial；6. 同句不重复登记。

## support_type 速查
数据句→direct；作者结论句→direct；背景铺垫→background；作者自述局限→partial（对强结论而言）；方向相反→conflicting。
