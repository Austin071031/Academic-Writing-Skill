# Academic-Writing-Skill

玻尔产品周赛学术写作赛道的 Skill 主仓库。每道题目一个一级文件夹（以题目命名），
题目下按版本号（`vX.Y.Z`）组织各次迭代的 Skill 完整内容。

## 目录结构

```
<题目名称>/
└── vX.Y.Z/            # 该版本的完整 Skill（SKILL.md + scripts/ + references/ + 文档）
    ├── SKILL.md       # 技能主说明（Agent 入口）
    ├── scripts/       # 运行脚本
    ├── references/    # 规则、模板、清单、示例
    └── README.md 等   # 使用说明与交付文档
```

## 版本规范

- 新版本在题目文件夹下新建 `vX.Y.Z/` 目录，完整自包含，不依赖其他版本目录。
- 版本号遵循语义化：修复为 PATCH，机制改进为 MINOR，工作流重构为 MAJOR。
- 每个版本目录内的 CHANGELOG.md 记录该版本相对上一版的变化。
- **每个版本目录必须包含 `SUBMISSION.md`**：记录该版本的 playground `Attempt ID`、挑战赛 ID 与题目、
  提交时间、状态与得分（未出分时写待回填，出分后回填），以及查询命令 `playground status --attempt-id <ID>`；
  以 `SUBMISSION.md` 为准；CHANGELOG.md 可另留一行 `提交：playground attempt <ID>（<challenge-id>，<题目>）` 便于检索。
  同一题目提交多次时按提交时间顺序与版本号顺序对应，重提不覆盖历史记录，追加新行。
- 历史版本已按 `playground attempt list --json` 的真实记录回填 `SUBMISSION.md`（同一挑战赛按提交时间顺序对应版本号顺序）；
  新提交请即时补写，重提在同一文件追加新行、不覆盖历史。
