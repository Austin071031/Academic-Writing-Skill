# Academic-Writing-Skill

玻尔产品周赛学术写作赛道的 Skill 主仓库。每道题目一个一级文件夹（以题目命名），
题目下按版本号（`vX.Y.Z`）组织各次迭代的 Skill 完整内容。

## 目录结构

```
<题目名称>/
└── vX.Y.Z/            # 该版本的完整 Skill（SKILL.md + scripts/ + references/ + 文档）
    ├── SKILL.md       # 技能主说明（Agent 入口）
    ├── scripts/       # 运行脚本
    ├── references/    # 规则、模板、清单、示例
    └── README.md 等   # 使用说明与交付文档
```

## 版本规范

- 新版本在题目文件夹下新建 `vX.Y.Z/` 目录，完整自包含，不依赖其他版本目录。
- 版本号遵循语义化：修复为 PATCH，机制改进为 MINOR，工作流重构为 MAJOR。
- 每个版本目录内的 CHANGELOG.md 记录该版本相对上一版的变化。
