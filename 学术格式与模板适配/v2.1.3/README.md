# 学术格式与模板适配 · v2.1.3

基于 **v2.0.0**（attempt 101404，得分 58.6667，本题首个有效出分基线）的单方向增量版。
本版唯一主线：**图表题注编号序列与正文交叉引用一致性自动核验**。
`compliance_check` 新增四个检查项（检测-only，不改稿）：题注编号无重复（重复 FAIL）、
题注编号序列连续（断号 WARN，支持 `图1` 与 `图1-1` 两种编号体系）、正文交叉引用均有
对应题注（孤儿引用 WARN，逐条定位）、题注均被正文引用（信息性 WARN）。
输出契约键名/结构零改动。

## 丢分根因

题注断号/重复、正文"见图N"而无对应题注，是真实学术稿件的高频缺陷，父辈完全没有覆盖；
赛题评分细则把"图表题注与交叉引用联动"明确列为创新增益的示例能力
（新增能力5/创新证据5），同时扩充了结果可核验性（5 分）的检查项覆盖面。
