# 章节规划判据表（planning rules）

## 大纲条目
- 标题层级：`#` 前缀、`1./1.1` 数字层级、`第X章`/`第X节`、`一、`。
- 字数预算：识别「（约N字）」「（N字）」；缺失时该节只报实际字数。
- 要素行：标题下一行含 `；`/`，`/`、` 分隔的短语归入该节必备要素。
- 文档总标题（论文大纲/提纲/目录/outline）不作为章节条目。

## 覆盖映射（材料 → 大纲）
- 直接映射：大纲条目编号与章节 heading_number 一致，或标题包含（≥2字）→ 该节全部段落记 score=1.0。
- 关键词补充：条目（标题+要素）与段落的字符 2-gram Jaccard ≥ 0.06 记 keyword 命中。
- 每个大纲条目取 top-8 证据段落；材料段落未被任何条目覆盖 → 缺口（material_gaps）。

## 必备论证要素（同义词表）
- 研究问题：研究问题/研究目标/科学问题/旨在/本文提出
- 方法：方法/实验/制备/测量/表征/流程
- 结果：结果/表明/显示/测得/达到/获得
- 讨论：讨论/归因/机制/解释/相比/原因
- 局限：局限/不足/展望/限制/尚未/仍需
大纲级完整性：五类要素均须有章节承接；缺失在 coverage_report 标 ⚠ 并在写作时补充或登记 uncertainty。

## 篇幅偏差
|实际/预算 - 1| ≤ 25% 通过；25-50% WARN；> 50% ISSUE（critical）。

## 章节重复风险
两个大纲条目的 top 证据段落集合重叠率 ≥ 50% → 重复对，须合并或改写论证角度。

## 数字溯源
- 豁免：年份 1900-2100；章节编号；图表/公式交叉引用目标。
- verbatim：数值原样出现于材料。
- derived：材料两值经 + - / 或 (a-b)/b 在 ±1% 内复现（含 ×100 百分比换算）；记录推导式。
- unverified：以上均不满足 → 不得写入结论性句子；移出正文或标「（数据来源待确认）」并登记 uncertainty。
- 容差只豁免舍入，不豁免篡改：verbatim 优先于 derived。
