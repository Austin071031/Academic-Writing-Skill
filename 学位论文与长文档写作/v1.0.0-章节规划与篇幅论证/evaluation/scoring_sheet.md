# 自查评分表（对应题面评分维度）

| 评分项 | 自查问题 | 本 Skill 机制 |
|-|-|-|
| 任务完成度 15 | 是否真正写出可用章节而非写作建议？ | Phase 3 按 chapter_plan 成稿；Phase 4 引擎校验 |
| 结果正确性 15 | 论断与材料是否对得上？ | 逐数值 verbatim/derived 溯源；evidence_map 逐条 |
| 结果完整性 5 | 大纲章节、论证要素、著录项是否齐全？ | coverage_report 五要素完整性；缺口显式列出 |
| 结果可核验性 5 | 能否追溯到大纲条目/材料/文献/版本？ | evidence_map、change_log、sha256 材料清单 |
| 质量增益 15 | 相比基础 Agent 是否稳定提升？ | 规划-写作-校验闭环；check 不过即降级 partial |
| 效率增益 5 | 是否减少人工通读与重排编号？ | 覆盖映射、缺口检测、编号连续性全自动 |
| 新增能力 5 | 基础 Agent 不具备的能力 | 篇幅偏差量化 + 数字四则派生溯源 |
| 运行稳定性 4 | 不同章节类型/篇幅/重复运行 | 脚本幂等；骨架 result 防空手 |
| 异常处理 3 | 材料缺失/大纲缺失/格式不支持 | 异常处置表 8 类；exceptions.json 如实记录 |
| 文档完整性 3 | 说明/示例/限制/失败模式 | README/USAGE/planning_rules/failure_modes 齐备 |
