# 中英文标点映射表（convert_engine.py `normalize_punct` 的规则说明）

> 目标规范为 GB/T 7714 时：英文条目半角、中文条目全角；APA/Vancouver 条目内部一律半角。
> DOI 子串（`10.\d{4,9}/...`）在任何方向转换中都被保护，绝不改写。

## 半角 → 全角（中文条目，lang=zh）

| 半角 | 全角 | 说明 |
|---|---|---|
| `,` | `，` | 作者间、刊名后 |
| `.` | `．` | 条末与分段点（不触及受保护的 DOI） |
| `:` | `：` | 页码前、DOI 前缀 |
| `;` | `；` | 多责任者/并列 |
| `(` `)` | `（` `）` | 期号括号 |

## 全角 → 半角（英文条目，lang=en，反向恢复空格）

| 全角 | 半角 |
|---|---|
| `，` | `, ` |
| `．` `。` | `. ` |
| `：` | `: ` |
| `；` | `; ` |
| `（` `）` | ` (` `)` |

## 语种判定与混排

- 条目语种来自 parse_library 的 `language` 字段（按题名+刊名是否含 CJK 判定）。
- 中英文混排文献库**按条目 language 分别处理**：不存在"整库统一一种标点"。
- 中文条目内的西文片段（如 DOI、英文专名）保持原样；仅结构标点转全角。

## 已知边界（诚实声明）

- 中文条目中含小数点（如版本号 `v3.2`）会被转成全角点；罕见，发现后列入 manual_confirmations 人工复核。
- 作者姓名内部的逗号（`Smith, John`）在转换前已完成名字形归一（`Smith J`），不会残留半角逗号被误转。
