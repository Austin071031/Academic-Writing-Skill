## 已知限制（诚实记录）

1. latex 稿件的 `\cite{key}` 键不在数字重排范围（键不携带列表号；如需键级映射属v1.0.0/3 范畴）。
2. 上标引用 `¹` / `[^1]` 形态只被解析不被重排（numeric 正则口径）。
3. 正文一句里**同一标记**多次引用同一编号会按 set 去重压缩（符合 GB/T 习惯，但与原文"故意重复"的罕见写法有差异）。
4. 插入条目若 Agent 未补正文引用，IV-2（无缺口）会 FAIL——这是特性不是缺陷，但要求 Agent 知晓。
