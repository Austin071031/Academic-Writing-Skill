# test_texts.md — 合成测试文本（全部为合成文本，非真实稿件）

三段合成测试文本，各针对一种典型陷阱。用法：作为稿件输入跑 Phase 1-4，
对照"期望行为"检查 decisions 与产物。配套文献库可复用任意含对应主题条目的 bib/ris。

## 测试 1：段末堆引用陷阱（位置判断）

```markdown
钙钛矿太阳能电池的光电转换效率已从 3.8% 提升至 25% 以上。
其稳定性问题主要源于钙钛矿层的水氧敏感性。
界面钝化被证明可以显著延长器件寿命。
```

- **陷阱**：三个论断句分属三个独立事实。基础 Agent 倾向于段末一次挂 `[1-3]`。
- **期望行为**：写 3 条 decisions（均为 quantitative_fact / others_result），
  引擎在每句句末各插一个标记：`…25% 以上[1]。…水氧敏感性[2]。…器件寿命[3]。`
- **检查**：placement_audit 的 `post_insertion_misplacement_suspects` 为空；
  段末 30 字符内只有第 3 个标记（它本就属于段末句）。

## 测试 2：需一句多引（合并正确性）

```markdown
固态电解质的离子电导率在室温下已可超过 10 mS/cm，接近商用液态电解液水平。
```

- **陷阱**：该量化论断由两条文献（期刊论文 + 综述）共同支撑。
- **期望行为**：一条 decision，`entry_ids: ["R0xx", "R0yy"]`（或两条指向同一句的 decisions），
  引擎输出**单个**合并标记，如 `…水平[1-2]。` 或 `…水平[1,4]。`
- **检查**：正文不出现 `][` 相邻双标记；audit 的 `multi_cite_merges` 中
  `merged_single_mark=true` 且 `no_adjacent_brackets=true`。

## 测试 3：作者新结果不应加引用（判断克制）

```markdown
本文采用溶胶-凝胶法制备了 Li7La3Zr2O12 电解质片。XRD 结果显示所得样品为纯立方相，
相对密度达 96%。烧结温度对晶粒尺寸的影响见图 2，随温度升高晶粒明显长大。
```

- **陷阱**：段中"相对密度达 96%"是量化数据，但它是**本文自己的结果**；
  基础 Agent 容易见到数字就挂引用，制造虚假溯源。
- **期望行为**：citation_decisions.jsonl 对该段**零条** decision
  （"溶胶-凝胶法"本身为公知方法、未沿袭特定文献时亦不引）。
- **检查**：edited_manuscript.md 中该段无新增标记；change_log 无对应该段的 insert_citation。
