# 校准自检脚本判定细则（check_calibration.py）

## 锚点约定

脚本按句检查，句子与比较登记（comparisons.md）通过两种方式关联：

1. HTML 注释锚：句尾写 `<!-- C1 -->`（推荐，交付稿可保留或删除——保留更利于复核）；
2. p 值匹配：句中 p 值与登记行 p 值一致。

建议写作时每条比较句至少满足其一，保证 C3/C4 能定位。

## C1 强断言 + 统计锚

- 强断言词命中任一（显著、大幅、明显、急剧、significantly、markedly、dramatically、substantially、drastically）即要求同句存在统计锚：`p<`/`p=`/`n=`/`CI`/`±`/`数字%`。
- 注意中文"明显"日常也修饰"明显不同"——若实际是级 2 比较，应改写为"无显著差异"而不是依赖脚本放过。

## C2 无 p 值禁用"显著"

- comparisons.md 中没有任何 p 值记录时，正文出现"显著/significant"即 fail。
- 这是防止在没有统计输出的材料上虚构显著性的硬约束。

## C3 不显著比较不得方向化

- 登记为级 2 且句中带锚的比较句，若含方向词（高于/低于/增加/降低/increase/decrease/higher/lower……）且不含否定语境（无显著/no significant/did not），fail。
- 正确写法见词典级 2：把方向句改为"相当/无显著差异"。

## C4 单条件现象须限定

- 登记为级 4 且句中带锚的句子必须含限定词（仅/只有/只在/only），否则 fail。

## C5 比较句基线

- 含方向词的句子须满足其一：(a) 句中至少两个数值；(b) 含图/表引用（视为回指基线）；(c) 带 HTML 注释锚。
- 该检查是启发式，可能误报修辞性用法（如"温度升高导致反应加快"这种机制句——机制句本不应在结果段，应移讨论段）。

## 人工兜底

脚本通过不等于表述正确——它只抓最常见的五类失准。交付前仍须人工逐句核对：每句措辞强度与 comparisons.md 定级一致。
