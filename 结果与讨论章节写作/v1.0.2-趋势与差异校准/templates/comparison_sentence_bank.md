# 比较句式库（按比较类型）

## 两组比较（有 p 值）

显著（级 1）：
- 中文：与{对照}相比，{处理}显著{升高/降低}{指标}（{a} → {b}，{+X%}，{检验}，p = {p}，n = {n}，图{x}）。
- 英文：{Treatment} significantly {increased/decreased} {quantity} relative to {control} ({a} to {b}, {+X%}; {test}, p = {p}, n = {n}; Fig. {x}).

不显著（级 2）：
- 中文：{处理}组与对照组{指标}相当（{a} vs {b}，p = {p}，图{x}）。
- 英文：{Quantity} was comparable between {treatment} and {control} ({a} vs {b}, p = {p}; Fig. {x}).

边缘（级 3，有 p）：
- 中文：{处理}组呈{升高}趋势但未达统计学显著（{a} vs {b}，p = {p}，图{x}）。

## 多组/梯度比较

剂量-反应：
- 中文：{指标}随{因子}剂量单调{上升/下降}：{d0} → {d1} → {d2}（图{x}）；{趋势检验或"未进行趋势检验，为描述性观察"}。
- 英文：{Quantity} changed monotonically with {factor} dose ({d0} → {d1} → {d2}; Fig. {x}); {trend test or "no trend test was reported; descriptive observation only"}.

组间两两比较（须注明校正方法）：
- 中文：多重比较采用{Bonferroni/Tukey/FDR}校正；校正后 {组对} 差异{仍显著/不再显著}（p = {p}，图{x}）。

## 时间过程

- 中文：{指标}在{t1}升至峰值 {v}，随后回落至 {v2}（图{x}）；与基线相比，{t2}时差异{显著/不显著}（p = {p}）。

## 相关（非比较）

- 中文：{X}与{Y}呈{正/负}相关（r = {r}，p = {p}，图{x}）；相关性不代表因果。
- 英文：{X} correlated {positively/negatively} with {Y} (r = {r}, p = {p}; Fig. {x}); correlation does not imply causation.

## 交互作用（若材料含双因素）

- 中文：{因子A}的效应受{因子B}水平影响（交互作用{检验}，p = {p}）：在{B1}水平下……，而在{B2}水平下……。

## 幅度表达规范

| 写法 | 例 |
|-|-|
| 相对变化 | 较对照组 +73% |
| 倍数 | 为对照组的 1.7 倍 / ×1.7 |
| 绝对差 | 升高 7.4 个单位 |
| 效应量 | Cohen's d = 1.8（大效应） |

禁用：不附数字的"大幅""明显"。
