# 四层局限写作模板

局限段不追求"全面自责"，追求**每条局限都具体、都说明威胁对象、都给出改进方向**。按四层组织；某层确无实质局限时可省略该层，但须在 uncertainty 说明。

## 模板骨架

```
本研究的局限存在于以下层面。
方法层面：{具体方法选择}可能{影响}。例如，{细节}。该局限主要影响{哪条结论的外推/精度}；未来可通过{改进}加以缓解。
样本层面：{样本量/来源/代表性}。例如，{n = 128，单中心}。因此{结论}在{更大人群/其他物种/其他材料体系}中的外推性有待验证。
测量层面：{测量手段的分辨率/频次/代理性}。例如，{X 仅基线单次测量，无法刻画暴露变化；Y 为代理指标}。这可能{低估/高估}真实效应。
统计层面：{检验效能/多重比较/混杂校正/模型假设}。例如，{未测量混杂 Z；样本量对中等效应的检验效能有限}。相应的{结论强度}应视为{提示性而非确证性}。
```

## 每层写作要点与示例

### 方法层面

- 要点：设计选择（横断面 vs 纵向）、处理方式（体外 vs 体内）、流程环节（提取、培养条件）。
- 例："本研究采用横断面设计，无法确立 X 与 Y 的时间先后；纵向随访设计可进一步厘清时序关系。"
- 反例（禁止）："实验方法还不够完善。"（无对象、无后果、无改进）

### 样本层面

- 要点：量（检验效能）、来源（单中心/单物种/细胞系代表性）、选择偏倚。
- 例："队列仅纳入单一中心的 128 例受试者，且年龄中位数偏低，结论向老年人群外推需谨慎；多中心、大样本队列可提高代表性。"

### 测量层面

- 要点：分辨率、检测限、频次（单次 vs 重复）、代理指标效度、观察者偏倚。
- 例："X 暴露仅于基线测量一次，未能刻画暴露的时间变化，可能使关联估计向无效值偏移；重复测量或纵向建模可改进。"

### 统计层面

- 要点：混杂校正、多重比较校正、模型假设、缺失数据处理、检验效能。
- 例："分析未校正未测量的混杂因素（如 Z），观察到的关联可能部分由混杂驱动；敏感性分析或工具变量方法可评估残余混杂。"

## 威胁-改进映射要求

每条局限必须同时回答三问：

1. **威胁对象**：影响哪条具体结论（回指正文论断编号或图号）？
2. **威胁方向**：使结论偏强、偏弱、还是仅限制外推？
3. **改进路径**：哪个具体做法可缓解（不是"今后加强研究"）？

## 语气校准

- 局限陈述用中性动词（"可能低估""有待验证"），不用自我贬低（"本文存在严重缺陷"）。
- 局限与结论强度联动：写了统计局限（未校正混杂），相应结论的措辞必须已在正文中降级——前后不一致是复核重点。
