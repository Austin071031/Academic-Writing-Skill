# 相关-预测-因果三级措辞边界表

## 1. 三级定义与判据

| 级 | 名称 | 判据（材料中需能支撑） | 允许句式 |
|-|-|-|-|
| A | 相关 | 同时测量两个变量，报告 r/β/OR 及 p | "X 与 Y 呈正相关（r = 0.71，p = 0.003，图3A）" |
| B | 预测 | 模型在独立数据上的预测性能（交叉验证、外部验证、AUC/R²） | "基于 X 的模型可预测 Y（交叉验证 R² = 0.62）" |
| C | 因果 | 随机分组干预 + 对照 + 前测后测（或等价设计：自然实验、工具变量、断点回归） | "X 处理使 Y 升高（随机分组，p = 0.002，图1B）" |

**判级顺序**：先看是否级 C 设计（材料明确随机化/干预）；再看是否级 B（预测验证）；都不是则级 A。判据在材料中找不到证据时，按更低级处理。

## 2. 因果定级登记（design_notes.md）

```
K1 X 与 Y 正相关 (r = 0.71, p = 0.003, 图3A) → 级A
K2 高剂量处理使 X 升高 (随机分组, p = 0.002, 图1B) → 级B
K3 X 通过 Y 通路起作用 → 级C(推测)
```

写作时级 B 论断句尾加 `<!-- K2 -->` 锚供审计脚本豁免。

## 3. 各级的措辞边界

### 级 A（相关）——禁止因果词

- 可用：相关、伴随、与……有关、随……增加而增加、correlated with、associated with。
- 禁止：导致、引起、造成、促进（机制义）、leads to、results in、drives。
- 级 A 结论句建议固定后缀："相关性不代表因果"（首次出现时）。

### 级 B（预测）——禁止机制词

- 可用：预测、可估计、模型在验证集上……、predicts、estimated。
- 禁止：解释（机制义）、说明（因果义）、决定。预测关联不等于机制理解。

### 级 C（因果，限定条件）——必须带条件边界

- 可用：使、导致、引起（仅限登记过的条件：剂量、体系、时间窗）。
- 句式："在本实验条件下（{剂量/时间窗}），X 处理使 Y 升高……"——条件边界不可省略。
- 禁止外推："X 通常使 Y 升高""普遍导致"——把单条件因果写成普遍规律。

### 级 D（推测）——全部标注

- 任何超出数据的机制解释："我们推测{机制}（推测，尚待验证）。"
- 级 D 不得出现在结果段；讨论段每条独立标注。

## 4. 转述他人文献时的同级约束

- 对方是相关性研究：转述用"该研究观察到 X 与 Y 相关"，不得写"该研究证实 X 导致 Y"。
- 对方是随机对照：可转述因果，但保留其条件（人群、剂量）。

## 5. 机制推测标注规范

- 中文："我们推测……（推测，尚待验证）"；若给出验证路径："……可通过{具体实验}加以验证"。
- 英文："We speculate that … (speculation, to be tested)"；"This could be tested by …"。
- 讨论段中同一推测不重复标注超过一次，但分散的多条推测各自标注。
