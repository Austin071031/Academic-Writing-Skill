# 组织模式决策规则

## 模式 A：按图序（默认）

每幅主图（或其逻辑单元）对应一段，段落顺序 = 图序。

适用：图表本身就是研究的推进主线（图1 建立表型 → 图2 验证机制 → 图3 功能验证）；任务未指定组织方式时一律用此模式。

优点：审稿人与读者按图索骥；引用锚点天然到图级。
风险：跨图的比较被切碎——若某论断依赖两图合并证据，在较晚出现的段落中回引（"结合图1B 与图2A 可见……"），并在 outline 中注明跨图关系。

## 模式 B：按研究问题

每段回答一个研究问题（Q1、Q2……），段内可并行引用多图。

适用信号（满足其一即优先模式 B）：

- task.md 明确给出研究问题列表或假设 H1/H2/H3；
- 图序与逻辑顺序不一致（如方法学图插在中间）；
- 单图信息量极小（每张图只有一条曲线），按图拆段会产生碎片段落；
- 材料是单一问题下的多条件比较（剂量-反应+时间-反应）。

段首用主题句点明问题："为检验 X 是否调控 Y，我们比较了……（图2A–C）。"

## 模式选择记录要求

在 outline.md 顶部写明：所选模式、选择理由（引用上述信号之一）、段落数预估。模式选择与理由会被复核，理由必须对应材料的真实特征，不得套话。

## 段落类型的比例控制

- 呈现型段落（新观察）：每章 1–3 段。
- 比较型段落（组间/时间/剂量比较）：紧随对应呈现段。
- 阴性结果段落：独立成句或成小段，不得藏在呈现段末尾一句带过；典型写法："值得注意的是，Z 处理未引起 W 指标的显著变化（10.2 ± 1.1 vs 9.8 ± 0.9，p = 0.41，图3C），提示 W 不是该通路的下游效应指标。"
- 每段长度目标 120–300 字（中文）/ 120–250 词（英文）；最长最短比 ≤ 5。
