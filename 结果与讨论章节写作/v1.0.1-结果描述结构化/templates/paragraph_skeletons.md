# 段落骨架

## 结果段骨架（四种句型够用，按段落类型组合）

1. **主题句**：「图{n}考察了{问题}。」/「为确定{X}对{Y}的影响，我们比较了{条件}（图{n}）。」
2. **呈现句**：「在{条件}下，{指标}为 {数值}{单位}（n = {n}，误差为{SD/SEM/CI}，图{n}{面板}）。」
3. **比较句**：「与{基准}相比，{处理}使{指标}{升高/降低} {幅度}（{检验}，p = {p}，图{n}{面板}）。」
4. **梯度句**：「{指标}随{剂量/时间}呈{单调/非单调}变化：{水平1} → {水平2} → {水平3}（图{n}{面板}）。」
5. **阴性句**：「{处理}未显著改变{指标}（{数值} vs {数值}，p = {p}，图{n}{面板}）。」

段内顺序建议：主题句 → 总体呈现 → 分组比较 → 梯度/阴性补充 →（可选）跨图回引。段尾不允许多余的解释句；如确有承上启下需要，用纯事实概括："综合图1 与图2，{可直读的事实概括}。"

## 讨论段骨架（五语步，每步至少一句，可扩展为多段）

1. **复述主要发现**：「本研究的主要发现是{一句话}【数据：图{n}】。」只复述结果段已陈述的事实，不新增数据。
2. **文献对照（一致）**：「该结果与 {Author, Year} 在{体系}中的报道一致，其{关键数值/结论}与本研究相近。」
3. **文献对照（不一致）**：「与 {Author, Year} 的结果相反，{差异的具体表现}。这种不一致可能源于{样本/方法/测量层面的具体差异}。」
4. **机制解释（推测须标注）**：「{已证实的中间环节}可解释上述现象；我们推测{更深机制}也可能参与（推测，尚待验证）。」
5. **意义与边界**：「上述发现支持{有限结论}；鉴于{方法/样本/测量/统计层面的具体局限}，结论外推至{更大范围}需谨慎。」

## 衔接与主次

- 段间推进靠问题逻辑（是什么→是否依赖条件→机制线索→功能后果），不靠时间顺序流水账。
- 主要发现所在段落前置；方法性、阴性结果放后但不得删除。
- 同一指标跨图出现时，第二次起用简称并回引首次定义处。

## 语言寄存

- 中文：书面语、无人称主语优先（"本研究观察到……"），避免口语连接词（"然后""接下来"）。
- 英文：被动与主动混合，优先 "we observed / compared / quantified"；避免 "we think / nice / very"。
- 术语首次出现给全称+缩写（人工智能（AI）；reinforcement learning (RL)）。
