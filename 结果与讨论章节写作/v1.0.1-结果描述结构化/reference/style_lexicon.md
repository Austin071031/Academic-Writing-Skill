# 词汇边界表：描述 / 解释 / 评价

写作前把本表放在手边；check_structure.py 的 R1–R3 按此表扫描。

## 1. 结果段允许（描述性谓词）

| 中文 | 英文 |
|-|-|
| 升高、降低、增加、减少、保持不变、无显著变化 | increased, decreased, remained unchanged |
| 呈剂量（时间）依赖 | in a dose- (time-) dependent manner |
| 高于、低于、与……相当 | higher than, lower than, comparable to |
| 出现、观察到、检测到、未检出 | observed, detected, was detected / not detected |
| 峰值出现在、降至、恢复至 | peaked at, declined to, recovered to |
| 正相关、负相关（仅陈述相关系数时） | positively / negatively correlated (r = …) |

## 2. 结果段禁止（解释性谓词，只能出现在讨论段）

| 中文 | 英文 | 说明 |
|-|-|-|
| 表明、说明、证实 | indicates that, suggests that, demonstrates that | 这些都是"论断"而非"观察" |
| 由于、因为（引出机制） | due to, because of | 因果归属属于解释 |
| 提示……机制、这意味着 | is consistent with the notion, this means | 机制推断 |
| 归因于、归咎于 | attributed to | 因果归属 |

**替代写法**：把"结果表明 X 升高提示 Y 通路激活"拆为两句——结果段："X 由 10.2 升至 27.6（p = 0.003，图2A）"；讨论段："X 升高可能反映 Y 通路激活（推测，尚待验证）【数据：图2A】"。

## 3. 结果段禁止（评价性词汇，全文都少用）

令人惊讶、出人意料、有趣的是、值得注意的是；interestingly, remarkably, surprisingly, importantly, notably。数据自己会说话；确需强调时，在讨论段用"该效应幅度（×2.7）大于多数同类报道"这类可核验的比较替代形容词。

## 4. 讨论段强度词汇（与证据强度匹配）

| 证据强度 | 可用 | 说明 |
|-|-|-|
| 本研究数据直接支持 | 支持、与之一致、 corroborates | 须紧跟数据锚点 |
| 本研究数据部分支持 | 提示、与……相符（有限） | 须说明限制条件 |
| 纯推测 | 我们推测……（推测，尚待验证） | 必须带标注 |
| 文献结论 | 某某报道/发现 | 必须给具体引用 |

## 5. 人称与语态

- 中文结果段用无人称或"本研究"；英文用 "we"（期刊惯例允许）或被动。
- 避免 "In this paper, we will show" 之类承诺式开头；结果段直接陈述。
