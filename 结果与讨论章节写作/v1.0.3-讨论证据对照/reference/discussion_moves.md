# 讨论段五语步结构与关系句式

## 语步 1：复述主要发现（1–2 句）

- 只复述结果段已陈述的事实，不新增数字。
- 句式："本研究的主要发现是……【数据：图1B】。" / "The principal finding of this study is … [Data: Fig. 1B]."

## 语步 2：与文献一致的对照（每条文献一段或一句）

- 句式："该结果与 {Author, Year} 在{体系}中的报道一致，后者观察到{其关键结论}【文献：{Author, Year}】。"
- 必须讲出"一致在哪"（方向、量级、条件之一）。

## 语步 3：与文献不一致或未复现的对照

- 句式："然而，{Author, Year} 报道{相反结果}【文献：{Author, Year}】；这种不一致可能源于{具体原因：样本来源/处理方式/测量手段/统计方法}。"
- 原因必须落到具体层面；两个以上候选原因用"或"连接并说明各自依据。

## 语步 4：机制解释

- 已证实的中间环节（本研究数据支持的链条）：可以直接陈述并给数据锚。
- 更深机制：一律"我们推测……（推测，尚待验证）【数据：图2A】"。
- 禁止把推测写成事实；禁止在讨论段引入结果段没有出现过的数据。

## 语步 5：意义与边界

- 意义句式："上述发现提示{有限的应用/理论含义}，为{领域}提供了{具体贡献}。"
- 边界句式："鉴于{具体局限}，该结论外推至{范围}需谨慎。"
- 意义的强度受证据分级约束（见趋势校准方向的原则，此处同样适用）。

## 关系词清单（语步 2/3 必须使用其一）

一致类：与……一致、corroborates、is consistent with、replicates、extends（拓展到新材料）。
不一致类：与……相反、contrary to、differs from、we did not replicate。
部分一致类：方向一致但幅度不同、条件不同、仅在部分指标一致。

## 只堆引用的反面模式（禁止）

"已有研究表明 X 重要 [1-3]。Y 也很关键 [4-7]。Z 同样参与 [8-10]。"——没有一句说明这些文献与本研究的关系。每个引用必须回答："它和我的结果一致吗？为什么？"

## 锚点格式

- 中文：【数据：图2B】、【文献：Zhang, 2020】
- 英文：[Data: Fig. 2B]、[Ref: Zhang, 2020]
- 句内位置：锚紧跟被支撑的论断之后， before 句末标点或紧随其后均可，全篇统一。
