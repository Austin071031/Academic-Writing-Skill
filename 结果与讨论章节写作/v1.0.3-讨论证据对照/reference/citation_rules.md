# 引用核验判定细则（verify_citations.py）

## V1 引用匹配

脚本识别三种引用格式：

1. `Author et al. (2020)` / `Author and Author (2020)` / `Author (2020)` / `（Author, 2020）` / `（Author 等，2020）`；
2. `[n]` 编号制（与 reference_keys.json 的条目顺序号匹配）；
3. `(Author, 2020)` 括号制。

匹配逻辑：姓氏（首字母大写，支持常见变音字符）+ 年份 与 `reference_keys.json` 中的 `(key.lower(), year)` 匹配；编号与条目序号匹配。**任一无匹配即 fail**——视为虚构引用或张冠李戴。

### reference_keys.json 的准备质量直接决定 V1 有效性

- 从论文末尾参考文献逐条抽取第一作者姓氏与年份；
- 同姓不同年的条目都保留（多行）；
- "et al." 前只取第一作者，正文若引用第二作者（如 "(Smith and Jones, 2020)" 而 Smith 是第一作者）也能匹配——脚本同时识别 "and" 结构的第一位。

### 常见 fail 与处置

| fail 场景 | 处置 |
|-|-|
| 正文写 (Li, 2021)，列表无此人 | 删除该论断或改写为不依赖文献的弱表述 |
| 年份手误（2020 写成 2021） | 改正文，不改文献列表 |
| 编号 [12] 超出列表长度 | 核对原意后改编号或删除 |
| 列表解析遗漏（乱码/换行错位） | 修复 references.txt 与 reference_keys.json 后重跑 |

## V2 论断句锚点

- 范围：讨论部分（## 讨论 / ## Discussion 标题之后）。
- 豁免句：不含论断动词（CLAIM_VERBS 词表：表明/支持/一致/相反/推测/suggest/consistent with 等）的纯过渡句、复述句中不含动词变体的句子。
- 注意：语步 1 复述句"本研究的主要发现是……"不含词表动词时可能被判豁免，但仍应主动加锚——脚本是底线，不是上限。

## V3 矩阵关系列

- 解析 `| Mx | ... |` 行：类型列含"文献"而关系列无"一致/相反/不符/不适用/N/A"即 fail。
- 表格分隔行（|---|---|）自动跳过。

## V4 推测标注

- 矩阵中存在推测型行时，正文全文须至少出现一次"推测，尚待验证 / speculation, to be tested"类标注；建议每处推测各标注一次（脚本只查存在性，人工复核看逐处）。

## 引用格式合规（脚本不查，人工核对）

- task.md 指定制式（GB/T 7714、APA、Vancouver）时按制式排版；
- 作者-年份制全文一致，不混用编号制；
- 中文任务中 "Zhang 等（2020）" 与 "(Zhang et al., 2020)" 不混排。
