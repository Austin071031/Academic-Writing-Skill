# 结果段与讨论段模板（数据与图表读数方向）

语言以 task.md 要求为准；未指定时中文任务用中文、英文期刊用英文。以下示例为中文骨架，英文写作时按同结构替换（英文句式见文末）。

## 结果段组织模式（二选一，task.md 指定则从其规定）

### 模式 A：按图序（默认）

每图一段（或视内容量一段覆盖一图的多面板）：

```
【主题句】图{ n }展示了{该图回答的研究问题}。
【数值呈现】在{条件}下，{指标}为 ({值} ± {误差}){单位}（n = {n}，误差为{SD/SEM/95% CI}，图{n}{面板}）。
【组间比较】与{对照}相比，{处理组}的{指标}{升高/降低}至 ({值} ± {误差}){单位}，差异{具有统计学意义（{检验}，p = {p}）/未达统计学显著（p = {p}）}。
【小结，可选】上述结果表明{仅限可直读事实的概括，不含机制}。
```

### 模式 B：按研究问题

每段围绕一个研究问题（一个问题可跨多图），段内引用格式与模式 A 相同，引用写到子面板：「（图2B；图3A）」。

## 讨论段组织模式

```
【主要发现复述】本研究观察到{一句话，锚点：图/表}。
【与文献一致之处】该结果与 {Author, Year} 的报道一致，其{对象}中{数值/结论}……
【与文献不一致之处】然而 {Author, Year} 报道{相反结果}，差异可能源于{样本/方法/测量层面的具体差异}。
【机制推测，必须标注】我们推测{机制}可能解释了上述现象（推测，尚待实验验证）。
【意义与边界】上述发现支持{有限结论}；但限于{方法/样本/测量/统计层面的具体局限}，尚不能得出{更强的结论}。
```

每条论断后必须紧跟证据锚点：【数据：图2B】或【文献：Author, Year】。

## 数值书写规范

1. 有效数字与材料一致：材料给 3 位有效数字，正文不写成 4 位；计算汇总值比原始数据少一位。
2. 误差值写法：`(61.4 ± 3.8)%`（括号包住数值与误差）或 `61.4% ± 3.8%`（单位只出现一次亦可），全篇统一。
3. p 值：照抄统计输出；输出为 `<0.05` 时正文写 `p < 0.05` 并注明原文未给精确值。
4. 单位换算后数值：台账登记换算前后两个值，正文用换算后值并在首次出现处注明（如 "298 K（25 °C）"）。
5. 倍数/百分比变化：写明基线与方向，"较对照组降低 29.7%（87.3% → 61.4%，图1A、1B）"。

## 英文句式对照

- 数值呈现: "Under {condition}, {quantity} was ({value} ± {error}) {unit} (n = {n}; {SD/SEM/95% CI}; Fig. {n}{panel})."
- 组间比较: "Compared with {control}, {treatment} {increased/decreased} {quantity} to ({value} ± {error}) {unit} ({test}, p = {p})."
- 未显著: "The difference did not reach statistical significance (p = {p}), and we therefore refrain from claiming a {direction} effect."
- 机制标注: "We speculate that {mechanism} may account for this observation (speculation, to be tested)."

## 禁止事项

- 结果段出现解释性词汇：因为、由于、说明、表明、证明、可能、提示……机制（属于讨论段）。
- 无锚点数值：任何数字后必须能定位到图/表/统计输出（台账 id）。
- 把 SEM 当 SD 报告，或反之；把 95% CI 写成 ± 值而不注明。
