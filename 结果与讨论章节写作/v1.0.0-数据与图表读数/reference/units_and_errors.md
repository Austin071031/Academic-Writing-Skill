# 单位、误差棒与读数规则

## 1. 误差棒类型判别（优先级从高到低）

1. **图注声明**：图注写 "Data are mean ± SD" / "mean ± SEM" / "error bars represent 95% CI" —— 以图注为准，台账 error.type 照抄。
2. **正文方法部分**：图注未声明时查 Methods 的统计分析小节，常见表述 "data are presented as mean ± SEM unless otherwise noted"。
3. **惯例推断（仅作标注，不直接采用）**：n 很小时（n ≤ 5）论文多用 SEM 使误差棒显得小——只能作为写 uncertainty 的理由（"图注未注明误差棒类型，按惯例可能为 SEM，待确认"），不能作为台账依据。
4. **判不出**：error.type = "unknown"，confidence = medium，正文写 `(61.4 ± 3.8)%（误差类型未注明，图1）` 并在 uncertainty 中说明。

**常见错误警示**：SEM = SD/√n。n=3 时 SEM 仅为 SD 的 58%。把 SEM 当 SD 报告会夸大样本间变异，是审稿人最常抓的错误之一；反之则夸大精度。

## 2. 单位换算表（常用）

| 量 | 换算 |
|-|-|
| 能量 | 1 kcal/mol = 4.184 kJ/mol；1 eV = 96.485 kJ/mol = 23.061 kcal/mol |
| 压强 | 1 bar = 100 kPa = 0.9869 atm；1 atm = 101.325 kPa |
| 长度 | 1 Å = 0.1 nm = 100 pm |
| 温度 | T(K) = t(°C) + 273.15 |
| 浓度 | 1 M = 1 mol/L = 10³ mM = 10⁶ µM |
| 质量 | 1 Da ≈ 1.66054×10⁻²⁷ kg |
| 反应速率 | 1 mol/(L·s) = 1 M/s |
| 磁场 | 1 T = 10⁴ G |

规则：正文全篇统一一种单位制；换算值的有效数字位数不超过原始值；台账 unit_note 记录换算式。

## 3. 有效数字

- 照抄原始数值的有效数字位；不确定度（±值）通常保留 1–2 位。
- 汇总计算：乘除结果的有效数字位数 = 各量中最少者；中间计算多保留一位，末步四舍五入。
- 例子：87.3 与 61.4 求变化率：(87.3−61.4)/87.3 = 29.7%（3 位有效数字，与原始一致），不写成 29.6678%。

## 4. 位图读数方法（无数值表时）

1. 渲染高分辨率图（≥200 dpi）。
2. 确认坐标轴：线性/对数、刻度间隔、单位、零点是否截断（截断轴的柱图必须说明）。
3. 逐面板读数：先读轴，再读柱/点位置，最后读误差棒端点。
4. 读数精度声明：按轴分辨率声明（如 "纵轴刻度间隔 10%，读数误差约 ±2%"），台账 confidence = medium。
5. 对数轴换算：读出的像素位置须按对数刻度换算，禁止按线性插值。

## 5. 多面板图与补充材料编号

- 主图面板用字母：图2A、图2B；正文引用必须到面板级（"图2B" 而非 "图2"），除非该论断覆盖全部面板。
- 补充材料：图S1、表S2、补充材料图S3——编号原样照抄，不得把 S1 写成 1 或并入主图。
- 双栏跨页图（图1在页2、图注在页5）：台账 quote 记录页码。
- 一张图含多个实验（面板 A 为 western blot、B 为定量）：台账按面板拆条，quantity 写清。

## 6. 统计量书写

| 统计量 | 正文写法 | 注意 |
|-|-|-|
| p 值 | p = 0.002 / p < 0.001 | 照抄输出；不要写 p = 0.000 |
| 均值±误差 | (87.3 ± 4.1)% | 数值与误差小数位对齐 |
| 检验名 | one-way ANOVA + Tukey 检验 | 首次出现写全称，可附缩写 |
| 自由度 | F(2, 12) = 6.42 | 照抄输出格式 |
| 效应量 | Cohen's d = 0.83 | 若材料给出则必须一并报告 |
| 样本量 | n = 3（生物学重复） | 区分 n（重复）与 N（个体数） |
