# 章节结构与叙事顺序判据（section_flow 规则说明，可复核）

## 1. 章节角色归类

标题关键词匹配（`scanutil.ROLE_MAP`，12 类角色）：摘要/关键词/引言/相关工作/方法/实验/结果/讨论/结论/致谢/参考文献/附录。未命中归 `other`。已知边界：

- "模型与方法"含"方法"→ method；"实验结果"含"结果"→ results（关键词按 ROLE_MAP 顺序先命中者赢，复核时留意）。
- 刁钻标题（"我们的办法""实证检验"）归 other，引擎不为其判缺失也不判逆序——漏报高发区，见 failure_modes.md。

## 2. 规范叙事顺序

`CANONICAL_ORDER = 摘要 → 关键词 → 引言 → 相关工作 → 方法 → 实验 → 结果 → 讨论 → 结论 → 致谢 → 参考文献 → 附录`。

- 逆序对判定：角色序列中任意 i<j 且 rank(role_j) < rank(role_i)。每条逆序对一条 move finding，随附具体两节名（如"结果 先于 方法"）。
- 常见合法例外（复核时删除）：期刊模板要求"结果与讨论"合一、快报类文体允许结论前置、参考文献按引用顺序编号出现（此时允许其随首次引用位置出现）。

## 3. 篇幅阈值

占比 = 章节字符数 / 非后置章节（排除参考文献/附录/致谢）总字符。

| 规则 | 阈值 | 动作 |
|-|-|-|
| 单节占比 | >55%（`THRESH.section_imbalance`） | split：按主题拆小节、细节移附录 |
| 方法章占比 | <8% 且存在结果/实验章 | add：方法过薄，扩充或回收散见方法描述 |
| 引言占比 | >35% | move：技术/文献细节后移至相关工作或方法章 |

阈值依据：正常 IMRaD 稿件中方法约占 15-30%、引言 10-20%；55%/8%/35% 设在经验分布尾部之外，只对明显失衡报警；所有占比写入 section_map.json 供复核。

## 4. 标题层级

- 相邻有级标题层级差 >1（如 H1 直接接 H3）→ reorder（补中间层级或降级标题）。
- 同级同名标题出现两次 → merge 候选（同名章节使叙事线断裂；若二者职责不同应改名而非合并，由人工裁决）。
- 章节下 n_para=0 → 空章 add（标题与内容悬空；文首标题/题名著者项除外）。

## 5. 信息释放顺序

- **缩写首现**：正则 `[A-Z][A-Z0-9]{1,7}s?`（容忍复数 LIBs/LEDs；白名单排除罗马数字 II/III、国别 US/UK、出版标识 DOI/ISBN 等）。在首现句及其前后各一句内查三种定义模式：`full name (ABBR)`、`中文全称（ABBR）`、`ABBR（全称）`；均未命中 → "缩写首现未定义"（add 补定义）。
- **回指悬空**：句含"如前所述/如上/上述/aforementioned/as mentioned above"；与其前 200 词（约 600 字符）的内容词 Jaccard <0.02 且前文长度 >50 字符 → add_transition 候选。
- **方法泄漏**：结果/讨论/结论章某段落含 ≥2 句方法性描述（"采用/步骤/配置为/参数设置/球磨/烧结/we use/experimental setup"等）→ move 到方法章，结果章保留指向性一句。

## 6. 编辑动作约束

每个 finding 的动作 op ∈ {move, merge, split, narrow, qualify, add, add_transition, add_limitation, reorder}；instruction 必须给出"移到哪/与谁合并/从哪拆/补在哪"，不允许"建议优化结构"这类不可执行表述。

## 7. 降级与豁免

- 全文仅 1-2 节：核心缺失一律降级 low（0.55），注明"短文档降级"。
- genre 含"综述/review/survey"：豁免方法章/结果章缺失（综述可无独立方法/结果）。
- 后置章节（参考文献/附录/致谢）不参与占比分母，但其逆序（参考文献夹在正文中间）照常报警。
