# 误报模式与人工复核要点

| 误报源 | 表现 | 复核动作 |
|-|-|-|
| 摘要与引言/结论天然重叠 | 摘要整段与引言首段 Jaccard≥0.55，被判"跨章重复" | 不删：该对已进入 structural_echo_pairs（confidence 0.5），逐条裁决——留点题骨架句（研究对象+主要结论），删展开性复述句 |
| 方法章标准表述重合 | 实验设置（温度/时长/设备型号）在方法章与实验章各写一遍 | 多为必要复现：若一处供复现、一处供讨论，驳回；若逐字重复且仅隔几段，合并 |
| 文献综述的同义复述 | 相关工作章转述两篇文献的相似结论，近似重复区间内 | 综述的合理密度：驳回 RD-B/D，除非两段逐字级重复 |
| 结论回收承诺被当重复 | 结论章重述摘要结论句（≥0.55） | 点题性回收是文体要求：走结构性呼应裁决，不直接 merge |
| 图表标题/公式段落 | "图1 显示…""表2 列出…"类段落彼此相似 | 图表题注天然同构：若 n_char≥40 且被成对命中，驳回 |
| 短段低重叠连锁 | 方法章每段只有 1–2 句，相邻段 Jaccard 普遍<0.05 | 步骤性文本本就话题跳转：只保留跳变确有损论证的条目，其余驳回 |
| 平铺无标题文本 | 全部段落同章，跨章判据失效，衔接类候选暴增 | 全部下调置信度 ≤0.5，报告标注"结构信息不足"，靠人工通读 |
| 内部句子数超上限 | 长段句子 >30 句时拆分检测跳过 | 人工检查该段是否需拆分；超大段通常先按小节标题拆 |

## 漏报高发区（Agent 第 7 步重点通读）

- **语义级同义复述**：整段换一套措辞说同一件事（无共同 3-gram），词面方法盲区——通读各章首段与结论段；
- **段内重复**：同一段内两个句子复述同一断言（引擎只查跨段/跨句对中的跨章句对）；
- **伪过渡**：后段以"此外"开头但内容与上段无任何逻辑关系（CONNECTIVES 命中后不报，需人工看语义）；
- **拆而未尽**：段落相似度 0.03–0.05 之间的"轻度混杂"，未达拆分阈值但两个话题已互相干扰。
