# 误报模式与人工复核要点

| 误报源 | 表现 | 复核动作 |
|-|-|-|
| 文献综述句被当作"前文承诺" | "已有工作表明…[n]" 命中首尾无呼应 | 删除：引语不是本文承诺 |
| 同义改写导致假断裂 | RQ 用"膨胀"，结果章用"体积变化"，覆盖率低于阈值 | 删除：人工确认语义对应已成立 |
| 章节角色误归类 | "模型与方法"归 method 失败 → 判"方法章缺失" | 删除并在 uncertainty 记录归类失败 |
| 编号 RQ 拆散 | RQ1/RQ2 同句列出被抽成一条 | 接受：在报告备注，不必拆 |
| 贡献句出现在摘要 | 摘要中的贡献与引言重复，被判两条 | 合并：保留引言处一条 |
| 全文无结论章 | "无呼应"类连锁误报 | 先处理"核心章节缺失"，连锁条目降级 |
| 平铺无标题文本 | 角色矩阵全空，大量"无承接"候选 | 全部下调置信度 ≤0.5，报告标注"结构信息不足" |

## 漏报高发区（Agent 第 7 步重点通读）

- RQ 以问句形式隐含在段落中（无提示词）；
- 贡献主张分散在方法章各节首句（"本节提出…"）；
- 结论回答了 RQ 但答非所问（词面重叠高、语义不对应）——词面方法天然盲区，必须人工判断。
