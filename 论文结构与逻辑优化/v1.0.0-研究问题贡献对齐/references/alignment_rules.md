# 对齐判据（rq_engine 规则说明，可复核）

## 1. RQ 抽取

提示词正则（`scanutil.RQ_CUES`）：研究问题/本文旨在/旨在/试图解决/核心问题/为了回答/研究目标/we aim/this paper aims/RQn…。命中句即 RQ 候选；`RQ_NUMBERED` 提取编号（RQ1/问题一）用于归组。

## 2. RQ×章节覆盖矩阵

- 内容词集合：中文二字组 + 英文实词（去停用词），见 `scanutil.terms`。
- 覆盖率 = Jaccard(RQ 内容词, 角色章节全部句子的内容词)。角色由标题关键词归类（`ROLE_MAP`）。
- 判定：方法章与实验章覆盖均 <0.20 →「无方法/实验承接」；结果章与结论章均 <0.20 →「无结果/结论回应」。
- 阈值 0.20 的依据：词面重叠天然偏低（同义词不重叠），0.20 足以排除"完全无交集"，又不会对正常改写误杀；所有中间值写入 rq_map.json 供复核。

## 3. 贡献×证据三档裁决

- 证据段落：角色 ∈ {results, experiment, discussion} 且含带单位数字或图表锚点。
- 与证据段落最大重叠 ≥0.25 → supported；0.12–0.25 → weak（补交叉引用）；<0.12 → unsupported（删除/降级主张）。
- 「贡献主张缺失」：全文无贡献提示词时给出 medium 级提示（综述类文体可不设贡献节，由人工确认）。

## 4. 首尾呼应

- 摘要+引言中含论断提示词（表明/证明/显著/shows…）的句子 = 前文承诺。
- 与结论各句最大 Jaccard <0.35 →「承诺未兑现」候选。
- 已知误报源：文献综述句（"已有工作表明…[2]"）会被命中，复核时删除（见 failure_modes.md）。

## 5. 编辑动作约束

每个 finding 的动作 op ∈ {move, merge, split, narrow, qualify, add, add_transition, add_limitation, reorder}；instruction 必须给出"移到哪/与谁合并/从哪拆/收窄到什么范围"，不允许"建议重写本节"这类不可执行表述。
