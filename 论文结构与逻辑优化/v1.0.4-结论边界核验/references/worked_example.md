## 输入片段（合成）

```
## 摘要
本文研究硅碳负极的包覆工艺。实验表明，200 圈循环后容量保持率为 65.2%。
## 3 结果
首效为 87.3%。200 圈循环后容量保持率为 65.2%。容量保持率与包覆厚度呈正相关。
## 4 结论
首效达到 91.0%。包覆工艺完全解决了膨胀问题，所有体系适用。本文工艺提升了循环稳定性。
```

## 作者复核流转

- **采纳**：按 action 执行编辑（91.0% 改回 87.3% 或补出处），在 edit_plan.json 将 review_status 改为"采纳-已执行"。
- **部分采纳**：结论保留提升表述但改为"在本文硅碳体系下观察到……"，删除"所有体系适用"。
- **驳回**：若 91.0% 实为另一批实验数据（稿件漏引），驳回并在 uncertainty 记录"出处缺失但数据真实"，同时建议补引。
