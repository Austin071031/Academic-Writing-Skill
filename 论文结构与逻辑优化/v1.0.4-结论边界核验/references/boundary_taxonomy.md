# 结论边界类结构问题分类（标注模板）

| 编号 | 类型 | 定义 | 典型锚点 | 推荐动作 |
|-|-|-|-|-|
| CB-A | 无源数字 | 结论/摘要数字在源章三层匹配皆失败 | 结论句中的数字 token | narrow：补出处或删除/改为正文数值 |
| CB-B | 数字不一致 | 数字与源章数值接近但不可由舍入得到，或格式不统一 | 结论 vs 结果章同指标 | qualify：核对并统一精度与格式 |
| CB-C | 因果超界 | 结论因果句仅相关性证据支撑（或无证据可核验） | 含"导致/提升/improve"的结论句 | narrow：降级为关联表述，或补设计引用 |
| CB-D | 绝对化 | 结论含全域量词（所有/任何/完全/never） | 结论句中的绝对词 | qualify：限定适用条件 |
| CB-E | 推广超界 | 结论范围词超出方法/实验章实际测试条件 | "所有体系/通用/universal" | qualify：限定为已测体系，或补多体系实验 |
| CB-F | 缺限制说明 | 无局限性表述 / 位置不当 / 仅一句无量化边界 | 全文或致谢/附录 | add_limitation / move / add |
| CB-G | 摘要结论不符 | 同语境句对中摘要与结论数字不一致 | 摘要句 × 结论句 | narrow：以正文为准两侧统一 |

## 复核三问（每条候选必答）

1. 该数字/范围词/因果词的原文锚点确实在结论性位置吗？（引言转述、文献综述句不是本文结论）
2. "无源"是真无源，还是语义出处（被引文献数据、单位换算、同义指标名）？（查 structure.json 源章原文与 boundary_audit.json 的 matched_source）
3. 建议动作执行后结论尺度是否与证据匹配？（降级后的表述不能被结果章数据再次推翻）

标注一律使用 findings.json schema；新增条目的 id 续接现有编号。
