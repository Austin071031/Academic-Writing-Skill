# 误报模式与人工复核要点

| 误报源 | 表现 | 复核动作 |
|-|-|-|
| 期刊模板要求的逆序 | "结果与讨论"在方法前的快报模板被判顺序倒置 | 删除：非缺陷，报告备注"模板所致" |
| 参考文献按引用顺序出现 | 首引处即列"参考文献"被判不在末尾 | 删除：数制允许随首引出现 |
| 综述类文体缺方法/结果章 | 引擎已按 genre 豁免，但 genre 未写入 case.json 时仍报 | 删除并在 uncertainty 记录"文体豁免" |
| 标题归类失败 | "我们的办法""实证研究"归 other → 漏判逆序/误报缺失 | 人工归类后增删条目 |
| 缩写白名单不全 | 领域惯用缩写（XRD、SEM）被报未定义 | 删除：学科约定俗成可不定义；或保留 low 提醒 |
| 缩写定义模式刁钻 | "the so-called LIBs""LIBs, namely lithium-ion batteries"未匹配模式 | 人工确认语义已定义 → 删除 |
| 回指为常识性省略 | "如前所述"指 obvious 内容，前文无同词但有同义 | 人工确认语义对应 → 删除 |
| 标题同名但职责不同 | "实验"（装置章）与"实验"（结果章）同名 | 改名而非合并：驳回 merge，改 add 改名建议 |
| 平铺无标题文本 | 角色序列仅 other，大量缺失/降级候选 | 全部下调置信度 ≤0.5，报告标注"结构信息不足" |
| 短文档/摘要体 | 全文 1-2 节报核心缺失 | 已自动降级 low；确认体裁后可整批驳回 |
| 图注不在文本层（v2.0.4） | 真实稿件图注随图片存在，md/txt 抽取后只剩"（图1）"式引用 → 报"图表引用悬空" | 确认原稿图注是否存在；存在则驳回，并在 uncertainty 注明"图注不在文本层" |
| 子图写法 图1(a)（v2.0.4） | "图1(a)"引用按图1 统计；仅有"图1(a)…图1(b)…"子图注而无总图注时，图1 被判无定义 | 子图注独立成段即视为图1 定义；否则人工确认总图注是否在图片内，相应驳回 |
| 表格跨页重复标题（v2.0.4） | 跨页续表重复"表3（续）"表头，同一编号出现多个"定义" | 编号按集合去重，不产生额外 finding；无需处理，仅需知道定义位置可能指到续表页 |
| 支撑材料引用"见图 S1"（v2.0.4） | 补充材料编号（S1、A1 等）含字母，正则不匹配，不报悬空——属有意豁免而非漏检 | 若稿件把支撑材料图当正文图用（"图S1"实为关键证据），人工补登"证据锚点在支撑材料" |
| 文献表分节（v2.0.4） | "参考文献"分多节或编号重启（如 [1]–[10] 与新增 [1]–[5]），条目计数与编号集合失真 | 按编号集合并集判定；分节文献表需人工核对条目总数后修正 xref_audit 再裁决 |
| 文献条目合并段（v2.0.4） | 解析把相邻文献行合并为一段，非方括号式"2022."年份可能被误当条目编号 | 已用"段首/句界标点后数字"模式规避；仍异常时对照 structure.json 原文核对 |

## 漏报高发区（Agent 第 7 步重点通读）

- 章节顺序正确但**节内**叙事倒置（方法细节写在结果小节开头、背景写在讨论末尾）——脚本只看节级顺序；
- 该拆分的边界在节内小标题之间（H2 过大但 H3 已合理分节）；
- 缩写以表格/图注首次出现（图注不进入正文句子流）；
- 同义章节名（"实证检验"实为 results）导致的逆序与缺失双重漏报——词面/关键词方法天然盲区，必须人工通读 structure.json 的章节清单。
