# 章节类结构问题分类（标注模板）

| 编号 | 类型 | 定义 | 典型锚点 | 推荐动作 |
|-|-|-|-|
| SS-A | 顺序倒置 | 角色序列出现逆序对（结果先于方法、结论先于结果、参考文献不在末尾） | 后出章节标题 | move：按规范论证序调整位置 |
| SS-B | 核心缺失 | 引言/方法/结果（或实验）/结论缺环；全文≤2节时降级提示 | (全文) | add：补独立章节或显式小标题 |
| SS-C | 篇幅失衡（该拆分） | 单节占正文 >55% | 该节标题 | split：按主题拆小节、细节移附录 |
| SS-D | 方法过薄 | 方法章 <8% 且结果章存在 | 方法章标题 | add：扩充制备/测试/统计细节 |
| SS-E | 铺垫过长 | 引言占正文 >35% | 引言标题 | move：技术/文献细节后移 |
| SS-F | 层级跳变 | 相邻标题层级差 >1（H1→H3） | 跳变标题 | reorder：补中间层级或降级标题 |
| SS-G | 该合并未合并 | 同级同名标题并存，叙事线断裂 | 两个同名标题 | merge：并入其一或改名区分职责 |
| SS-H | 该拆分未拆分 | 同节混入多主题/多体裁内容（方法泄漏入结果） | 混入段落 | move：该后移的细节移回方法章 |
| SS-I | 信息过早释放 | 缩写首现未定义；回指无前文对应 | 首现句/回指句 | add（补定义）/ add_transition（补所指） |
| SS-J | 空章节 | 标题下无段落，与后文关系悬空 | 空节标题 | add：补内容或删标题 |
| XR-A | 图表引用悬空 | 正文引用图/表编号无对应图注/表注定义（v2.0.4，dimension=argument_chain） | 引用句 | add：补图注/表注定义或修正编号 |
| XR-B | 公式引用悬空 | 引用式(n)/Eq.n 无对应编号公式锚点 | 引用句 | add：补公式编号或修正引用 |
| XR-C | 章节引用悬空 | "第N章/节""Section X.Y"目标不在标题编号集合中 | 引用句 | add：改正目标编号或改写指回 |
| XR-D | 文献引用悬空 | 引用 [n] 超出参考文献条目数 | 引用句 | add：补文献条目或修正编号 |
| XR-E | 文献条目未被引用 | [1..n] 中条目从未被正文引用 | 参考文献表 | narrow：删除或在正文补引 |
| XR-F | 图表编号不连续 | 被引图表均有定义但编号跳号（如图1、图3 无图2） | (全文) | reorder：编号连续化并同步引用 |

## 复核三问（每条候选必答）

1. 该逆序是否由期刊模板/文体要求所致？（模板所致 → 驳回）
2. 该"缺失"章节是否以别的名字存在？（角色误归类 → 删除并在 uncertainty 记录）
3. 建议的 move/split 执行后，论证顺序是否真正闭合？（只动位置不动内容，确认无信息丢失）

标注一律使用 findings.json schema；新增条目的 id 续接现有编号。
