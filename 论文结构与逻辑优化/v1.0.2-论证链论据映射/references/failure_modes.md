# 误报模式与人工复核要点

| 误报源 | 表现 | 复核动作 |
|-|-|-|
| 文献综述转述句 | "已有工作表明…[n]" 被抽为论断 | 正常：自带锚点判 strong，不入断裂清单；若引用在句末被切分到下一句则误 none，删除该条 |
| 数字无单位 | "容量保持率约八成" 无 `EVIDENCE_NUMBER` 锚点 → 假断裂 | 删除：人工确认段内确有数据，uncertainty 记录"锚点形式漏检" |
| 口语化图表指代 | "上图/下表/前文结果" 不匹配 图n/表n → 锚点漏检 | 删除并在 uncertainty 记录 |
| 段末统一标注引用 | 引用 [n] 在段末，论断句在段首 | 正常：同段锚点判 strong；若引用被分入下一段（换行问题）则误 weak，降级处理 |
| 结论复述摘要 | 结论句与摘要论断 3-gram ≥0.7 且都无锚点 → 疑似循环 | 多为误报：首尾呼应是正常修辞；确认两处确无独立证据才保留 |
| 定义性比较 | "A 优于 B 是众所周知的"（常识性比较）→ 比较无对象 | 人工判断：常识可删，领域论断需保留并要求出处 |
| 章节角色误归类 | 结果章被归 other → 锚点窗口统计不变但报告位置错乱 | 在 uncertainty 记录归类失败，按段落原文复核 |
| 平铺无标题文本 | 段落合并成大段 → 锚点窗口过宽，断裂漏报 | 全部下调置信度 ≤0.5，报告标注"结构信息不足" |

## 漏报高发区（Agent 第 7 步重点通读）

- 无论断提示词的隐性断言（"X 的效果是 Y 的两倍"——无"优于/显著"字样）；
- 图表存在但图注数据与正文论断数值不一致（锚点在、内容不符）——词面方法盲区，必须人工核对；
- 同一论据被多处论断反复引用支撑不同结论（论据过载）；
- 循环论证的异文形式（同义改写后 3-gram 相似度低于 0.7）——近似判定天然盲区，必须人工判断。
