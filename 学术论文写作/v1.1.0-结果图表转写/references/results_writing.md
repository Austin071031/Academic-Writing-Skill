# 结果节写作规则（数据保真）

## 1. 结果段组织
- 一段一图/表：先述数据事实（数值+单位+误差+样本量，全部带台账 fact_id），再一句归纳，不解释机制（机制归讨论节）。
- 顺序与图表编号一致：图 1→图 2→…；正文先引用，图表随后出现。
- 对照结构：先写对照组基线，再写处理组差异；差异给出绝对值与（如需）相对变化，相对变化标【计算值】。

## 2. 数字转写
- 单位照抄材料原文（`mg·L⁻¹` 不擅自改 `mg/L`；任务要求统一单位时统一并记 change_log）。
- 有效数字照抄：`92.30%` 不写成 `92.3%`（精度即信息）。
- 误差类型照抄：SD ≠ SEM ≠ 95% CI，三者不可互换；材料未注明类型 → `±1.8%【待确认：误差类型未注明】`。
- 显著性：材料给出检验方法与 p 值才写"显著（t 检验, p = 0.004）"；只给 p 值写"p = 0.004【待确认：检验方法未注明】"。
- 样本量：每组 n 必须写明；材料没有 → 【待确认：样本量未记录】。

## 3. 图注公式
```
图 N 　标题（一句话，说明什么条件下测的什么量）。
（n = X，数据为均值 ± SD；统计方法；*p < 0.05。数据来源：M02。）
```
- 图注只写材料中真实存在的信息；图中样式（颜色/标记）看不到就不写。
- 表注同理：表头单位、脚注说明缩写与统计口径。

## 4. 趋势≠因果（措辞三档）
| 证据 | 可用 | 禁用 |
|-|-|-|
| 干预实验+统计检验 | 提高/降低、显著 | 证明、机制性断言（除非材料有机制证据） |
| 组间比较无检验 | 提示、观察到、呈…趋势 | 显著、导致 |
| 相关关系 | 相关、伴随、与…一致 | 导致、决定、证明 |

## 5. 摘要—结果一致
摘要中的每个数字必须逐字出现在结果节；摘要不得引入结果节没有的数值。

## 6. 常见失分点（本 Skill 机检覆盖）
- 正文数字与数据文件不一致（numcheck FAIL）
- 引用了图 N 但没有图注（FAIL）
- 把"A 组高于 B 组"写成"A 导致 B 升高"（WARN）
- 百分比变化未标来源（须【计算值】豁免，否则 FAIL）
