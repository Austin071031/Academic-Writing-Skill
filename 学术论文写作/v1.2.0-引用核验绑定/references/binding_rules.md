# 论断—引用绑定规则

## 1. 绑定类型（引用必须匹配论断性质）
| 论断类型 | 应引文献 | 反例（错配） |
|-|-|-|
| 领域背景/常识性断言 | 综述、教科书 | 引一篇不相关实验论文充数 |
| 具体数据/数值（"前人达到 85%"） | 原始研究论文 | 引另一篇综述的转述 |
| 方法依据（"采用 X 法测定"） | 方法原始文献或标准 | 引用了结果论文而非方法论文 |
| 对比论断（"与文献趋势一致"） | 被对比的具体文献 | 引了主题无关文献 |

## 2. 装饰性引用识别（须删除）
- 句子删除该引用后论断依然完整且无需来源 → 装饰性。
- 同一位置堆砌 ≥4 条引用且无逐一对应 → 保留最直接 1–2 条。
- 文献表条目从未被正文引用 → 冗余条目，删除或找到应引位置补引（引擎判 FAIL）。

## 3. 引用错配处置
- 论断无文献支撑但有材料支撑 → 删引用、改用材料事实表述（材料事实无需文献引用）。
- 论断无支撑 → 删除论断或标【待确认：无支撑来源】。
- 引用存在但绑错句 → 移到它真正支撑的句子，记 change_log。

## 4. 复核方法（成稿前必做）
1. 跑 engine_check 生成绑定表；
2. 逐条读"所在句上下文"，回答：这条文献的题名/主题是否直接支撑该句？
3. 不确定的标 ⚠ 并在 uncertainty 列出，宁缺毋滥。
