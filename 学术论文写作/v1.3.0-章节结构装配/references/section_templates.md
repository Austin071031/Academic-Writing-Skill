# 章节模板与各节内容清单

## IMRaD 全稿（默认）
| 章节 | 内容清单 | 篇幅占比 |
|-|-|-|
| 标题 | 对象+方法+核心发现，≤25 字，不夸大 | — |
| 摘要 | 目的(1-2句)—方法(1-2句)—结果(2-3句含关键数值)—结论(1句)；无引用 | ≈5% |
| 关键词 | 4–6 个材料术语 | — |
| 引言 | 背景(有引用)→已知不足→本工作目标 | ≈15% |
| 方法 | 对象/样本量、仪器参数、步骤、统计方法；只写材料记录的 | ≈25% |
| 结果 | 一段一图表：数据事实(数值/单位/误差/显著性)→一句归纳 | ≈30% |
| 讨论 | 含义→与文献比较→局限(含材料缺口)→展望；趋势≠因果 | ≈20% |
| 结论 | 回答引言目标，不引入新数据 | ≈5% |
| 参考文献 | 按引用格式统一 | — |
| 声明字段 | 见 declarations.md | — |

## 摘要（单独任务时）
- 结构式摘要按"目的/方法/结果/结论"加小标题；非结构式一段成文。
- 双语摘要：中英逐句对应，数值、单位、术语缩写完全一致。

## 审稿回复信
- 逐条：审稿意见原文 → 回应（改何处/为何不修改）→ 稿件锚点（节号/图号）。
- 不承诺材料中不存在的实验；补做类意见标【待确认：需实验确认】。

## Cover letter
- 一段定位（领域+问题）、一段贡献（2-3 条，来自稿件）、一段声明（原创/无一稿多投/利益冲突）。

## 改稿任务的结构规则
- 保留底稿章节层级、图注编号、引用编号；改动逐条记 change_log（原句→新句→依据）。
- 压缩：先删无出处断言与重复句；扩写：只用材料中未用上的事实。
