# 材料组织规则

## 1. 冲突裁决优先级
同一参数多值时按序裁决并留痕：
1. **原始数据文件**（CSV/仪器输出）> 实验记录 > 底稿转述 > 二手引用
2. 时间更新的记录优先（材料有日期时）
3. 与任务直接相关的口径优先
裁决写入 change_log：`参数 X：采用 M02(v)，弃用 M05(w)，依据：M02 为原始数据文件`。
无法裁决 → 正文【待确认：冲突】+ uncertainty，**不得悄悄选一个**。

## 2. 冗余处置
- 内容近重复的材料：选信息最全/格式最可靠的一份作为引用源；
- 其余在 evidence_map 注"冗余同源于 M0x"，不重复计入证据；
- 冗余材料若数值不一致 → 转为冲突处理。

## 3. evidence_map.md 格式
```markdown
# 证据映射表
| # | 稿件论断/数字 | 类型 | 来源锚点 |
|---|---|---|---|
| 1 | 处理组产率 92.3%±1.8% | number | M02#l14 |
| 2 | 前人效率约 85% | citation | M05#l201（文献条目 R3） |
| 3 | 样本量 n 口径冲突 | gap | M02(n=3) vs M04(n=5)，按规则 1 采 M02 |

## 未使用材料
| 材料 | 弃用原因 |
| M07 questionnaire.csv | 与本文结果节无关（任务限定结果节） |
```
类型枚举：number / unit / citation / figure / method / claim / gap / conflict。

## 4. 缺失登记的使用
- unreadable 材料：相关部分写作时明确"该部分材料不可用"，不臆测内容；
- 无材料支撑的章节：标【待补：缺材料】而非省略；
- 所有缺失同步 result.json uncertainty。

## 5. 材料 → 正文的支撑自述
稿件方法节末尾（或任务指定处）附一句"材料依据说明"：
`本文数据来自 M01–M03（原始数据），方法描述依据 M04（实验记录），文献条目来自 M05。`
让评审一眼看到材料—正文对应关系。
