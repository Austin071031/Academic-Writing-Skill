# 章节模板（全得起来）

按 `brief.required_sections` 与任务体裁选模板；任务明确要求其他结构时以 task.md 为准。
每节详略：材料证据多的节详写，证据少的节简写并标缺口；**不允许为凑字数注水**。

## A. IMRaD 全稿（实验类论文默认）
1. **标题**：反映对象+方法+核心发现，≤25 字（或 task.md 要求）；不夸大。
2. **摘要**：目的(1-2句)—方法(1-2句)—结果(2-3句，含关键数值，全部出自 facts.json)—结论(1句)。无文献引用。
3. **关键词**：4–6 个，来自材料术语。
4. **引言**：领域背景（引用 bibliography 条目）→ 已知不足 → 本工作目标。背景断言必须有引用或材料支撑。
5. **方法**：按材料中的实验记录写：对象/样本量、仪器与参数、步骤、统计方法。只写材料记录的步骤；
   材料没写的参数标【待确认】，不得按"常识"补。
6. **结果**：按图表组织，一段一图/表：先述数据事实（数值+单位+误差+显著性，全部有出处），再一句归纳。
   不解释机制（留给讨论）。
7. **讨论**：结果的含义 → 与文献比较（引用绑定）→ 局限性（含材料缺口）→ 展望。趋势不写成因果。
8. **结论**：回答引言的目标，不引入新数据。
9. **致谢 / 资助 / 利益冲突 / 数据可得性声明**：材料提供则写，未提供写【待确认：材料未提供××声明】。
10. **参考文献**：按 citation_rules.md 格式统一。

## B. 仅结果节 / 仅方法节（单章任务）
- 结果节：A.6 规则 + 图注表注完整编号；开头一句交代数据结构（来自方法材料）。
- 方法节：A.5 规则 + 分小节（对象/装置/步骤/分析）；参数表用 Markdown 表格，数值照抄。

## C. 摘要 / 双语摘要
- 按 A.2；双语时中、英逐句对应，数值、单位、术语完全一致；术语首次出现给缩写（中文（English, ABBR））。
- 翻译任务：只转换语言，不增删事实；原文无出处的数字保留并标【待确认：底稿数值未见于本次材料】。

## D. 改稿（换受众/换体裁/压缩扩写）
- 保留底稿章节层级、图注编号、引用编号；改动逐条进 change_log：`原句 → 新句 → 依据（材料锚点/任务要求）`。
- 压缩：先删无出处的断言与重复句，保留全部有出处数值；扩写：只能用材料中未用上的事实补，不注水。
- 换受众：术语解释程度按受众调整，事实内容不变。

## E. 校对任务（以底稿为对象）
- 产物 = 修订稿 + 勘误表。勘误表逐条：`位置 | 底稿表述 | 材料依据 | 处置（改/删/标待确认）`。
- 数字、单位、图注编号、引用对应、章节缺项五类逐项过；check_consistency 报告作为主证据附交付。

## F. 审稿回复 / Cover letter（如任务要求）
- 逐条引用审稿意见原文 → 回应（修改了哪里/为何不修改）→ 指向稿件锚点（节号/图号）。
- 不承诺材料中不存在的实验；补做类意见标【待确认：需实验确认】。

## 篇幅控制
- 有 word_target：各节按 引言15% 方法25% 结果30% 讨论20% 其余10% 分配（±30% 可接受）；
  材料不足以支撑目标字数时写满事实为止，在 uncertainty 说明实际字数与原因。
- 无 word_target：结果+方法约占全文一半；摘要不超全文 5% 或 300 字取小。
