# 写作红线：事实保真规则（写得实）

本规则在分章写作时逐条执行；`check_consistency.py` 会在成稿后机读核验第 1、4 条。

## 1. 数字零臆造
- 稿件中每个数值、单位、样本量、误差范围、显著性标记，必须来自以下三者之一：
  1. `/app/work/facts.json` 中的条目（记录其 fact_id 进 evidence_map）；
  2. 材料文本锚点（`/app/work/text/Mxx.txt`，记录 seg_id/行号进 evidence_map）；
  3. task.md / case.json 中给定的约束本身（如"写 800 字"中的 800 不算实验数据，豁免）。
- 找不到出处的数字**不得写入**。宁写"实验记录了 3 次重复【待确认：底稿未给出具体数值】"，不得编造数值。
- 转写规则：单位照抄材料原文（如材料写 `mg·L⁻¹` 不改写为 `mg/L`，除非任务要求统一单位，统一时记入 change_log）；
  有效数字位数照抄；误差表述照抄（`±`、`SEM`、`SD`、`95% CI` 不互换——三者含义不同）。
- 统计显著性：材料给出 p 值/检验方法才可写"显著"；材料只说"升高/降低"就只写"升高/降低"。

## 2. 趋势 ≠ 因果
- 材料未做因果检验（随机对照、干预实验）时，禁用"导致/证明/决定/显著提升"；
  改用"提示/相关/伴随/观察到/与……一致"。
- 相关关系不得写成机制；机制性表述必须有材料中的机制证据或文献支撑（支撑文献进 evidence_map）。

## 3. 图注与表注
- 编号连续（图 1、图 2…；表 1、表 2…），与正文中"如图 N 所示"一一对应。
- 图注只描述材料中图面真实呈现的信息（坐标、组别、样本量、误差棒类型——材料写明才写）。
- 图片材料（status=image）中的数值**不得**凭视觉估计写入正文；必须引用时注明"见图 N（原图）"并标【待确认：图中数值需人工核对】。

## 4. 缺失、冲突与待确认
- 材料缺口（缺图注、缺样本量、缺方法细节）：就地标注 `【待确认：缺××】`，并写入 evidence_map 的 `type: gap`。
- 材料内部冲突（两处数字不一致）：采用与任务直接相关的口径，另一口径写入 `【待确认：M03 与 M05 口径冲突（xx vs yy）】`，并在 change_log 记录取舍。
- 底稿改写任务：底稿中已有的无出处数字**保留但标注** `【待确认：底稿数值未见于本次材料】`，不得悄悄删除或替换。

## 5. 不新增材料外事实
- 背景知识性表述（"X 广泛应用于 Y"）如无材料或文献支撑，删去或改写为不携带事实断言的过渡句。
- 任务明确允许补充外部文献时：只用真实可查的文献（作者、年份、期刊、DOI 齐全），
  在 evidence_map 标 `type: external`，并在 change_log 说明检索来源。

## 6. evidence_map.json 条目格式
```json
[
  {"claim": "催化效率达到 92.3%", "type": "number", "source": "F0017 (M02#row4)"},
  {"claim": "前人报道类似体系效率约 85%", "type": "citation", "source": "R003"},
  {"claim": "高温组样本量缺失", "type": "gap", "source": "M02 全文无记录"},
  {"claim": "X 机制已被证实", "type": "external", "source": "ext: 检索记录见 change_log"}
]
```
type 枚举：number / unit / citation / figure / table / method / claim / gap / external。
