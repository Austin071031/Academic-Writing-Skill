# 学术写作客户端

玻尔产品周赛第四期「学术写作客户端」五方向同题参赛作品。

赛题要求围绕“接收稿件—按指令修改—保留修订—导出可编辑文档”闭环开发可被
Agent 调用的 Skill，重点改善改得准、改得可追溯、格式不塌、交付可用。
本题五个版本各选一个截然不同的突破方向，共用同一套纯标准库确定性脚本骨架
（OOXML 工具包 + 锚定 + 契约化 result.json），各自叠加方向的深度机制。

## 共用骨架

- 纯 Python 3 标准库，零 pip 依赖；LibreOffice/poppler 缺失时诚实降级并留痕。
- 契约化 result.json：`case_id` + `output_contract` 全字段（缺失列
  `missing_fields`），status 如实（success/partial/failed），
  uncertainty 与 human_confirmations 单列。
- 原稿只读保全（/app/work/originals），一切修改发生在工作副本上。
- 锚定纪律：改不到唯一锚点就不改，进 human_confirmations，不猜。
