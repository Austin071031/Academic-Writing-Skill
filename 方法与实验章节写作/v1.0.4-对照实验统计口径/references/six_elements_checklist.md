# 六要素覆盖清单（七节骨架逐项核对）

写作前逐项问"材料里有没有"，写作后逐项问"正文写没写到、锚点挂没挂上"。

## 1 方法步骤
- [ ] 步骤有序编号，每步含输入/操作/输出
- [ ] 关键判断条件（停止条件、早退、筛选阈值）写明
- [ ] 没有把多步操作压成一句（检查"并""随后"连写的长句）

## 2 实验设置
- [ ] 硬件：机型/卡数/显存，带锚点
- [ ] 软件：框架与版本、CUDA、关键库版本，带锚点
- [ ] 训练/验证/测试流程分开描述，条件不串台
- [ ] 随机种子与重复次数写明；单次运行须声明

## 3 参数与来源
- [ ] 正文数值与附录A参数表逐行一致
- [ ] 每个参数有来源锚点（配置/日志/代码/论文页码）
- [ ] 跨来源取值不同时有取舍记录（changes.json）

## 4 数据集与划分
- [ ] 名称+版本（如 v1.2）、规模、来源/许可
- [ ] 预处理步骤与顺序
- [ ] 划分比例与随机方式（种子）、各子集用途
- [ ] 版本含混处已追问（防止复现失败）

## 5 对照实验
- [ ] 基线对象及版本/出处
- [ ] 对照条件是否同预算/同划分/同评测协议，写清
- [ ] 评价指标定义与统计方式（均值/最好/单次）

## 6 可复现清单
- [ ] 代码版本（commit/tag）与获取方式
- [ ] 环境（OS/Python/依赖版本）
- [ ] 训练与评测命令（可直接复制执行）
- [ ] 数据获取方式（URL/校验和/路径）

## 7 限制条件与适用范围
- [ ] 每条限制指向具体失效场景（"在 X 条件下不成立"，不写"存在一定局限性"式套话）
- [ ] 适用范围（数据域/规模/语言）写明
