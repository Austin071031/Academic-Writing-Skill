# 基础 Agent 典型失败模式（对照/统计视角对照自查）

1. **裸比较**："本文方法优于 BERT"——不同预算/划分/指标。→ 对策：可比性闸门 +
   不可比句式改写。
2. **编造统计**：默认写"三次取平均"或脑补 p<0.05。→ 对策：repeats/single_run_note
   强制 + 禁止编造条款。
3. **基线脑补**：引用训练数据里见过的"BERT 常见分数"。→ 对策：无材料即 gaps(high)。
4. **消融失据**：写"去除 X 后下降 2 点"但材料没有消融结果。→ 对策：value 必须有
   source_eid。
5. **指标混用**：Accuracy 与 F1 混在一句比较。→ 对策：一行一对 metric×split。
6. **预算失明**：不提预算，比较成断言。→ 对策：budget 必填 + 差异须 waiver。
7. **超时空手**：→ Phase 0 骨架 + 预算告急立即装配 partial。
