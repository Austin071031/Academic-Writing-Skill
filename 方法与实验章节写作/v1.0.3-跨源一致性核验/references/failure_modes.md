# 基础 Agent 典型失败模式（一致性视角对照自查）

1. **顺手抄值**：从论文正文抄 learning_rate，而日志实际跑的是另一个值。→ 对策：三级
   优先级，论文只作印证。
2. **无视冲突**：配置与日志不同，静默选其一，不说明。→ 对策：机检候选冲突必须裁决或升级。
3. **等价误判**：把 3e-4 与 0.0003 当冲突上报或当两个值写两遍。→ 对策：引擎归一化同组。
4. **阶段混裁**：把训练 batch 与评测 batch 的取值冲突混为一谈。→ 对策：按 scope 分别裁决。
5. **别名漏并**：lr 与 learning_rate 各裁一次，结论不一致。→ 对策：别名归并规范名。
6. **升级失语**：判不了的冲突直接删掉。→ 对策：escalated 必须带 question_for_author。
7. **超时空手**：→ Phase 0 骨架 + 预算告急立即装配 partial。
