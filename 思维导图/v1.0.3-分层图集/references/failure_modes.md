# 失败模式与对策（v1.0.3）

| 失败模式 | 症状 | 对策 |
|-|-|-|
| 一级分支按页码切 | 分支间语义重叠 | 按 atlas_design.md 的同维度原则重设分支 |
| 分支严重不均 | 一支 100+ 节点 | 接受截断并在 uncertainty 声明；或把该支再分两支 |
| 为凑单图删节点 | 信息丢失 | 禁止；让引擎进入图集模式 |
| 截断不声明 | 评审找不到深层节点 | uncertainty 必须列出被截断分支 |
| 跨图边丢失不说明 | 关系看起来断了 | 在总览图 note 或 uncertainty 说明跨图边存于 normalized.json |
| 索引与图不一致 | 手工改过渲染产物 | 只改 mindmap.json，重跑 atlas.py |
| 总览图当完整答案 | 评审漏看详图 | result.json 与 atlas.html 都列出全部图 |
