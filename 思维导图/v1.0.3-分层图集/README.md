# mindmap-atlas（分层图集式思维导图 Skill）

面向长材料/多文档的思维导图图集：**1 张总览图 + N 张分主题详图**。
Agent 组织完整逻辑树后，图集引擎按预算（总览 ≤20 节点、详图 ≤40 节点）自动拆分，
每图渲染六种可编辑/预览格式，节点编号全局稳定，evidence 单元号跨图一致，
并提供 atlas_index.md 与 atlas.html 导航。

## 特性

- 自动拆分与自动单图两种模式（规模 ≤40 节点时单图交付）
- 总览图节点附分支规模计数，详图聚焦单分支，防止"一张图看不清"
- 跨图稳定编号 + 索引，支持评审逐图核对与溯源
- 继承共享审计：fact quote 逐字、数字溯源、critical 闸门

## 使用

见 `SKILL.md` 与 `docs/USAGE.md`。仅依赖 Python3 标准库。

## 边界

- 一级分支设计由 Agent 负责（引擎只按分支拆分）；分支不均时详图截断到二级并在索引标注。
- 版本: v1.0.3。
