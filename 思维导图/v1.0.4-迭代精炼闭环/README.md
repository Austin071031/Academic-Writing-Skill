# mindmap-refine-loop（迭代精炼式思维导图 Skill）

"草稿 → 机检评分 → 按单修订"的质量闭环。引擎把题面五问
（抓得准/理得清/连得对/可追溯/实际有用）落成可计算的 rubric，
用**材料单元 ↔ 节点覆盖矩阵**找出重要未覆盖内容，输出按严重度排序的修复清单；
Agent 定向修订一轮后交付，并把两轮得分变化写入 stats 作为增益证据。

## 特性

- 五维机检评分（0-100）+ 综合分，全部指标可复算
- 重要未覆盖单元检出（含数字/标题/长段落却无节点引用的材料单元）
- 修复清单按 critical→high→medium→low 排序，逐条可执行
- 两轮得分对比写入 result.json stats，增益可验证

## 使用

见 `SKILL.md` 与 `docs/USAGE.md`。仅依赖 Python3 标准库。

## 边界

- 材料本身高度冗余时覆盖率有上限，引擎接受 uncertainty 说明而非强行挂无关节点。
- 建议修订一轮，最多两轮；评分是启发式，不替代人的最终判断。
- 版本: v1.0.4。
