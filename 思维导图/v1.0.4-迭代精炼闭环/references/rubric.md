# 五维 rubric 口径（v1.0.4，与 refine.py 常量一致）

## 抓得准（accuracy）

- fact quote 原文命中率（权重 0.6）：quote 去空白后必须是单元原文子串。
- 数字可溯源率（权重 0.4）：节点标题/note 中的数字（≥2 位或带 %）出现在其证据单元。
- 派生数字允许在 note 写明计算式（如"增幅 611% =(320-45)/45"），人审认可，机检按
  未命中计——因此能写原文数字就写原文数字。

## 理得清（structure）

100 起扣：深度超 5 每层 -8；扇出超 9 每处 -6；重复标题每个 -5；同级 kind 混杂（≥3 种
且 ≥3 子节点）每处 -3。

## 连得对（relation）

- 边证据率（0.5）：有 evidence 或 note 含"推断"的边占比；无边时按 0.5 中性计。
- 词表合法率（0.3）。
- 孤立事实节点率（0.2）：有证据但无边无子节点的叶节点占比（越低越好）。

## 可追溯（traceability）

- 证据节点率（0.5）：挂 evidence 的节点占比。
- 材料覆盖率（0.5）：被引用单元 / 全部单元，0.6 封顶（承认材料冗余）。

## 实际有用（usefulness）

purpose 与 audience 填写各 +30；kind 多样性每类 +8（上限内）；有待确认标注 +10；基线 +20。

## 覆盖矩阵方法

每个未被任何节点 evidence 引用的材料单元，与全部节点（标题+note）算 bigram Jaccard
相似度；最高相似度 <0.08 且重要度 ≥2（含数字/标题/长段落/结论性词汇加权）判为
"重要未覆盖"，进 high 修复项。重要度加权：heading+2、含数字+2、长段落+1、结论词+1。
