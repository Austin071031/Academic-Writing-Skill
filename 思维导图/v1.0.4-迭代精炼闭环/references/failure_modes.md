# 失败模式与对策（v1.0.4）

| 失败模式 | 症状 | 对策 |
|-|-|-|
| 为提分挂无关证据 | coverage 升但 quote 对不上 | 禁止；覆盖率有 0.6 上限，宁缺毋滥 |
| 覆盖率追满 | 把冗余单元硬塞进节点 | 冗余是材料属性，uncertainty 说明即可 |
| 只修低分项不看 critical | 分升但交付不可信 | critical 永远第一优先 |
| 草稿过度打磨 | 第一轮就花光预算 | Phase 1 限时成图，把判断留给修订轮 |
| 得分自评代替机检 | 口头声称质量好 | 必须贴两轮 refine_report 数据 |
| 修订破坏已好结构 | 第二轮分反降 | 对照 fix_list 逐条改，不大改结构 |
| 清单条目被删 | fix_list 与 report 不一致 | 保留原始报告，修订写 change_log |
