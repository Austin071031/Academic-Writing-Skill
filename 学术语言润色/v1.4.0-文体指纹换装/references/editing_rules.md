# 换装编辑规则（editing rules）

## 先守恒后风格（不可违背）

数值、单位、统计量、引用编号与 \cite 键、图表/公式/章节指向、专有名词拼写、
限定词强度（可能/有望/约 ↔ may/suggest/approximately）、否定范围、量词、
因果/相关性质——一律不动。风格换装只动：词形（口语→书面、宣传→中性）、
句式（悬垂修正、长句切分、名词化还原）、连接词（删冗余、补必要）、
人称（按文体换成"本文/本研究/被动/中性主语"）。

## 受控类型词表

grammar｜syntax｜collocation｜punctuation｜spelling｜long-sentence｜terminology｜
abbreviation｜register｜redundancy｜logic｜clarity｜hedging｜formatting｜other。
语域换装记 register；附带修的硬错误另记对应类型。

## 换装手法（register 类）

| 病灶 | 换装 |
|-|-|
| 但是/比如/做了/搞 | 然而/例如/开展（视文体） |
| 我们提出/我们发现 | 本文提出/本研究发现（中文稿） |
| very excellent / amazing | effective / notable（按证据强度） |
| 国际领先/首次（无证据） | 删除或降级为"率先（据我们所知）"并列人工确认 |
| completely solves | addresses / mitigates |
| Moreover×3 一段 | 留一个，其余删或换句间逻辑 |

## reason 质量标准

指向具体语言现象（哪个词/哪条指标），≥8 字；禁止"更通顺/更规范/更学术"类空话；
style_target 字段写"口语化→书面语"等一行概括；存疑句以"存疑："开头。
