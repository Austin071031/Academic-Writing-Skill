# 五种文体指纹画像（register profiles）

style_metrics.py 的 TARGETS 与本表一一对应。区间是经验带，不是法律；案例自带风格
指南优先于本表（把差异记入 target_profile.json 的 custom_rules）。

## 期刊论文

- 平均句长：中文 28–48 字 / 英文 18–28 词；长句占比 ≤35%。
- 限定词密度 0.15–0.6/句；弱档（可能/有望/may）常见于讨论，强档（证明/prove）罕见。
- 连接词密度 ≤0.8/句；*Moreover* 一段至多一个。
- 第一人称 ≤2 次（英文正文避 *I*；中文避"我们"作主语）。
- 宣传/绝对化词 0 容忍（国际领先/首次无证据/very excellent/best 无支撑）。

## 学位论文

- 句长放宽（中 25–50 / 英 16–30），长句占比 ≤45%；章节衔接显式。
- 人称 ≤4；中文用"本文/本研究"。

## 基金申请书

- 句长中 25–45 / 英 16–26；限定词密度 0.2–0.8（"有望/预计"高频是特征不是病）。
- 自信但不夸口：宣传词 0 容忍；评审视角三句话：可信、可行、创新。

## 审稿回复

- 短句优先（中 22–42 / 英 14–24，长句 ≤25%）；逐条对应；礼貌直接。
- 人称 ≤8（we 允许）；无情绪化表述。

## 英文摘要

- 150–250 词；句长 15–25 词；不引文献编号与图表；方法过去时、结论现在时。
- 第一句领域与问题，末句意义；连接词 ≤0.6/句。

## 指标解读提示

- 被动语态（英文）只报不测限：方法部分被动高属正常，不强制压。
- 限定词档位分布变化（强/中/弱计数）必须在 change_log 的 hedging 类型里逐条有理由。
- 长句为定义句/并列枚举句时允许保留，处置写入 resolutions.jsonl。
