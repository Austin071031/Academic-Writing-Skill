# 文体语域指南（register）

语域扫时按目标文体逐条核对。文体不明 → 按"期刊论文"执行并在 assumptions 注明。

## 期刊论文

- 摘要：背景一句、方法两句、结果带数值、结论一句；不引文献编号、不引图表。
- 方法：过去时、中性或被动主语；只写做了什么，不评价好坏。
- 结果：只报告观察到的事实；讨论才解释。
- 禁：*I*；*obviously/clearly*；无支撑最高级（best/first/novel 无证据）；口语缩写。

## 学位论文

- 允许更完整推导；章节衔接显式（"本章首先…其次…"）。
- 中文用"本文/本研究"，避免"我觉得"；英文 avoid "I" prefer "this thesis/we"。

## 基金申请书

- 评审视角：可信、可行、创新各有一句证据支撑的话。
- 自信但不夸口："有望/可能/预计"保留；不用"必将/彻底解决/revolutionary"。
- 中译英基金本：按英文信息重心重排（目标→路径→影响），不留中文排比句式。

## 审稿回复

- 逐条对应：先复述问题，再给修改位置与证据；不同意时给依据不辩解。
- 礼貌直接；不用 *as we already explained*。

## 英文摘要

- 150–250 词；方法过去时、结论现在时；第一句领域与问题，末句意义。

## 语域扫清单（回扫第 3 遍逐条过）

1. 人称：中文稿无"我们"主语堆叠；英文正文无 *I*、无 *don't/can't*。
2. 宣传词：very excellent / amazing / 国际领先 / 首次（无证据）→ 降级。
3. 绝对化：always/never/completely/彻底 → 有证据才留。
4. 口语化：但是→然而；比如→例如；做了→开展/进行（视文体）；像…一样→如同。
5. 限定词与证据强度匹配（见 lexicon.md）。
