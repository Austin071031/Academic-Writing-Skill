# 编辑规则速查（editing rules）

## 决策顺序（每句）

硬错误（grammar/syntax/collocation/punctuation/spelling）→ 悬垂与长句（syntax/
long-sentence）→ 术语与缩写（terminology/abbreviation）→ 语域（register）→
冗余与逻辑（redundancy/logic）→ 清晰度（clarity）→ 都无则 keep。

## 受控类型词表

grammar 语法｜syntax 句法｜collocation 搭配｜punctuation 标点｜spelling 拼写｜
long-sentence 长句切分｜terminology 术语统一｜abbreviation 缩写与首次出现｜
register 语域语气｜redundancy 冗余精简｜logic 逻辑连接｜clarity 表达清晰度｜
hedging 限定强度（原则上不出现；出现必过回译验证）｜formatting 格式｜other 其他

## 禁动清单

数值、单位、统计量、引用编号与 \cite 键、图表/公式/章节指向、专有名词拼写、
限定词强度、否定范围、量词、因果/相关性质。术语只在术语表内统一。

## 常见修法

- 口语化：但是→然而；比如→例如；做了实验→开展实验。
- 宣传化：very excellent→effective；国际领先/首次（无证据）→ 删除或降级。
- 中式英语：make an analysis of→analyze；there be 滥用；*Moreover* 一段至多一个；
  a accuracy→an accuracy。
- 悬垂：As shown in Fig. 2, we observe → Figure 2 shows。
- 时态：方法与实验过去时，普遍事实与结论现在时。

## reason 质量标准

指向具体语言现象（哪个词/哪种结构/哪条规则），≥8 字；禁止"更通顺/更规范/
语言优化"类空话；存疑句以"存疑："开头并进 manual_review_required。
