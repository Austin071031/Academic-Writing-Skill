# 增益证据包编写规范（gain evidence）

交付 `gain_evidence.md`，让评审不用推断就能看到"加载 Skill 带来了什么"。
只写可由产物直接佐证的事实，不写宣传话。

## 1. 修改前后量化对照

```markdown
| 指标 | 润色前 | 润色后 | 证据位置 |
|---|---|---|---|
| 语法/句法硬错误 | 7 处 | 0 处 | change_log.md grammar/syntax 类卡片 |
| 术语写法种数（受控概念） | 5 概念 11 种写法 | 5 概念 5 种写法 | terminology_table.md variants 列 |
| 缩写首现无全称 | 2 处 | 0 处 | change_log.md abbreviation 类卡片 |
| 口语/宣传词 | 4 处 | 0 处 | change_log.md register 类卡片 |
| 限定词跨档变动 | — | 0 处 | conservation_check.md |
| 数值/引用/图表指向变动 | — | 0 处 | conservation_check.md |
```

计数必须能从 change_log 卡片数出来，不许估算。

## 2. 评分细则自评（四维逐条给证据链接）

改得对 / 说得像 / 没改坏 / 讲得清 每条一行：状态（达成/部分/未达）+ 证据文件与位置
（如"讲得清：change_log.md 每张卡含原文/改文/类型/理由，抽样 B3-S2"）。
未达项如实写并说明原因——**自评有缺口比假装满分更可信**。

## 3. 对照公平性声明

固定句式照写："本次润色的输入为 /input 原始材料；术语表、风格规则均来自题面或
源文本本身，未引入外部知识；所有修改可回溯到 change_log 具体卡片；
与基础 Agent 的差异在于流程约束（逐句留痕、守恒自查、三遍回扫），
不在于获得了额外信息。"

## 4. 与现有方案的差异点（创新证据）

各写 2–3 句，聚焦"本流程能做到而对方难稳定做到"：
- 对基础 Agent：无约束时倾向整段重写、不留逐句痕、限定词易漂移；本流程逐句卡 +
  守恒证据使每处改动可复核。
- 对通用写作工具（Grammarly 类）：只报建议不交付逐句对照，不维护术语表，不认识
  引用编号与限定强度档位。
- 对翻译工具：中译英只做语言转换，不做语域控制与事实守恒检查。
- 对人工润色基线：人工一致性靠经验，本流程把术语表、强度档位、禁动清单显性化，
  可重复执行。

## 5. 可复用资产清单

列出本 Skill 附带的可复用文件（评分表、测试文本、词表、规则），说明各自用途与
使用条件——生态贡献的评分依据。
