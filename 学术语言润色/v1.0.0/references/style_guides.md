# 目标文体与语域指南（style guides）

按任务指定文体执行；文体不明时按"通用学术"档并记入 assumptions。每档列出：语气特征、
该做、不该做、示例改写。

## 通用学术（默认档）

- 客观、克制、可证；陈述与证据强度匹配；避免情绪化与营销词汇。
- 示例：*Our method is very powerful and achieves amazing results.* →
  *Our method improves accuracy by 3.1% over the baseline on the test set.*

## 期刊论文（research article）

- 摘要：独立成篇；背景一句、方法两句、结果带数值、结论一句；不用"本文将/我们试图"。
- 引言：从领域问题到研究缺口的漏斗结构；过去时叙述他人工作，现在时陈述普遍事实；
  研究贡献用现在时陈述句。
- 方法：过去时、被动或中性主语（*We optimized/The model was trained* 依期刊习惯）；
  步骤可复现，不评价好坏。
- 结果：只报告观察到的事实；讨论解释与局限；*suggest/indicate* 与证据强度匹配。
- 禁：*I*；*obviously/clearly* 预设读者立场；无支撑的最高级。

## 学位论文（thesis/dissertation）

- 允许更完整的推导与背景；章节衔接显式（"本章首先…其次…最后…"）；
- 致谢与原创性声明等字段不属于润色范围，除非任务要求。
- 人称：中文用"本文/本研究"，避免"我觉得"。

## 基金申请书（grant proposal）

- 评审视角：可信度、可行性、创新性三件事各有一句可被证据支撑的话。
- 语气：自信但不夸口；"有望""可能"保留不确定性，不用"必将""彻底解决"。
- 英文 proposal 避免 *revolutionary/game-changing* 类宣传词；用 *could enable/are expected to*。
- 中译英基金本：按英文 proposal 的信息重心重排（目标→路径→预期影响），不保留中文排比句式。

## 审稿回复（response to reviewers）

- 逐条对应：先致谢与复述问题，再给修改位置与证据；不同意时给出依据而非辩解。
- 礼貌、直接、不情绪化；不用 *as we already explained*。
- 修改说明指向具体页/行/图，保持与稿件一致的术语。

## 英文摘要（English abstract）

- 150–250 词；不引用文献编号（视期刊）；不出现图表引用。
- 时态：方法过去时，结果过去时或现在时，结论现在时。
- 第一句给领域与问题，最后一句给意义；不使用 *In this paper, we will...*。

## 语域检查清单（回读阶段逐条过）

1. 有无 *I/we* 误用、口语缩写（*don't/can't* 留在正文）？
2. 有无宣传词（*novel/unique/first* 无支撑、*excellent/amazing/perfect*）？
3. 绝对化表述（*always/never/completely/首次/彻底*）是否有材料支撑？无 → 降级。
4. 情态动词与限定词是否与服务对象（证据强度）匹配？
5. 中文稿：有无"我们"开头主语堆叠、"进行了大量的"类空转？
