# 审稿回复与论文修改 Skill · v1.0.0 意见拆解与覆盖台账

玻尔产品周赛第四期「审稿回复与论文修改」参赛作品（方向一：意见拆解）。

## 这是什么

一个可被 Agent 调用的 Skill：读入基线稿件 + 审稿意见清单，把每条意见拆解为原子子要求，建立"子要求→决策→编辑操作→证据"覆盖台账，驱动一次可复核的受控返修，交付修订稿、逐条回复信、修改定位、证据清单与五重交叉核验。

## 与基础 Agent 的差异（创新点）

1. **原子化拆解引擎**：连接词切分 + 动作信号过滤，把"一条意见多个要求"显式拆开，杜绝只答一半；
2. **跨意见重叠/冲突/依赖检测**：3-gram 相似度 + 方向相反词对，检出基础 Agent 难以稳定发现的交叉要求；
3. **覆盖台账终检**：audit 阶段强制每个子要求有明确处置结论，未覆盖即 FAIL；
4. **锚点编辑引擎**：声称的修改必须真实落在基线上，锚点失败不得谎称已改。

## 依赖与限制

Python 3.8+ 标准库；PDF 材料可选依赖 pdftotext（缺失时降级并记录）。只修订输入中实际提供的基线；不补做实验、不编造数据，未到位证据一律占位 + 清单 + 人工确认。
