# 诚实边界规则（红线）

1. 只修订组织方指定基线；不得声称修订了"完整原稿"或未提供的版本。
2. 不得冒称：真实审稿人逐字要求、真实补做了实验/重新分析、已联网核验文献原文、编辑部已接收。
3. 基线中不存在的数据、文献、实验结果，一律以【待补：具体说明】占位，并同时：
   - 在 evidence_checklist.md 建行（状态=无法补做/部分到位 + 替代说明）；
   - 在 result.json 的 manual_confirmations 列出；
   - 回复信中写明"将在获得 X 后填入"，不得写"已补充"。
4. 意见给出具体数值时（如审稿人说"应为 5 ℃/min"），可以使用，change_log 注明来源为该意见。
5. 锚点解析失败的修改不得保留在回复信的"已修改"声明中；要么修复锚点，要么降级为说明。
6. status 判定：全部子要求覆盖 + verify PASS → success；有未覆盖/未到位证据但不影响已做部分真实性 → partial 并说明；材料不可读/无法定位基线 → failed 并说明缺什么。
7. 公开论文链接仅为来源身份，不作为已核验内容引用。
