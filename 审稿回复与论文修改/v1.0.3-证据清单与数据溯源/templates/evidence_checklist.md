# 证据清单模板（evidence_checklist）

> 用法：优先用 `evidence_engine.py --stage demand` 自动生成草稿再终判；
> 仅当脚本不可用（如中间 JSON 缺失）时手工按本模板填写。
> 每个 needs_evidence 子要求至少关联一行；同一证据服务多个子要求只占一行。

## 填写规则

1. **编号**：EV1、EV2…… 按序编号；dispositions.json 的 evidence 字段引用同一编号表示共享；
2. **需求类型**：补实验 / 补数据 / 补文献 / 重做分析 / 其他证据（由 action_kind 映射，见 references/evidence_rules.md 第 1 节）；
3. **到位状态**（三选一，判据见 evidence_rules 第 2 节）：
   - 到位：证据已真实写入修订稿，无【待补】残留；
   - 部分到位：修改已落稿但含【待补：…】占位；
   - 无法补做：条件不存在/数据未采集/无法核验，必须给替代说明；
4. **出处**：基线内写 P###（如 baseline P004）；材料外写"材料外，待作者补充"；禁止写未经核验的文献条目；
5. **替代说明**：按 evidence_rules 第 3 节句式——原因 + 等效佐证/局限声明 + 去向；
6. **红线**：未到位证据不得冒称已补做；占位标记在证据到位前不得删除；每行变更同步更新回复信对应段落。
